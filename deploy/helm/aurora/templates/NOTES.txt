(generated database passwords, relay token), the Secret {{ include "aurora.caSecretName" . }} (the gateway CA PRIVATE KEY) and the ConfigMap
{{ include "aurora.fullname" . }}-config. Keep them to reinstall into this namespace with the old database volume; for a clean removal delete them:
  kubectl -n {{ .Release.Namespace }} delete secret {{ include "aurora.secretName" . }} {{ include "aurora.caSecretName" . }}
  kubectl -n {{ .Release.Namespace }} delete configmap {{ include "aurora.fullname" . }}-config
