# FIX-180: The gateway's HTTP/1 proxy ends a request whose body stalls (60 s idle → 408)

## Goal
Found by FIX-177's analysis (2026-11-19): the gateway's plain HTTP/1 proxy connection
(`services/aurora-gateway/src/proxy/listener.rs` `serve_plain`) has a `header_read_timeout` but no idle
timeout while reading a request body, so a client that stops mid-body holds the connection (and whatever
the decision path holds while it waits in `buffer_prefix`/`park`) until it closes. Only sandboxed agents
talk to this proxy, so it is resource holding, not exposure. Owner, 2026-11-19 (D-395): add an idle
timeout of **60 s** with no body bytes; the request ends with **408** and the connection closes.

## Change
1. A body-read idle timeout: 60 s without a new body byte (not a total-duration limit: a slow but
   moving upload keeps going). On expiry: answer `408 request_body_timeout` (C-1040, the standard error
   envelope) if no response has started, close the connection, write the request-log row with that code,
   and release anything the decision path held (a parked approval stays parked; the held request is
   dropped as a client abort is today).
2. The value is a constant in `crates/aurora-core/src/limits.rs` (`GATEWAY_BODY_IDLE_TIMEOUT`, 60 s),
   listed where the guards expect limits; not a setting.
3. The same timeout on the TLS (CONNECT) path if it reads request bodies through the same code; say
   which paths it covers.
4. Docs: `06` (the proxy's timeouts), `API_CONTRACTS` C-1040, `15` (operator note).

## Tests
- IT: a client that sends the head and half a body then stops gets `408` after the timeout (use a test
  override of the constant, not a 60 s sleep), the connection closes, the log row has
  `request_body_timeout`; seen hanging before (with a bound).
- IT: a body sent slowly but steadily (a byte every few hundred ms of the test timeout) is not cut.
- The FIX-177 regression test and the gateway suite (nextest) stay green.

## Ownership
`services/aurora-gateway/src/proxy/**`, `decide.rs` only where the held state is released,
