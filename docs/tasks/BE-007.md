# BE-007: `aurora-testkit` (ephemeral Postgres, mock upstream)

## Goal
Shared test utilities so service and e2e tests get a migrated database and mock HTTP upstreams in one line.

## Linked requirements
- M0/18 (`aurora-testkit`: ephemeral Postgres, mock upstream); decision I-06. Mock OAuth/OIDC servers are deferred to M1 (OIDC) / M3 (OAuth) tasks and recorded there.

## Context
- `crates/aurora-db` exposes `MIGRATOR`, `connect`, `migrate`. Dev server: `DATABASE_URL` in repo-root `.env` (`postgres://aurora:aurora@127.0.0.1:55432/aurora`).
- Workspace deps: `sqlx`, `tokio`, `wiremock`, `uuid`, `anyhow`. Do not edit root `Cargo.toml`.

## Scope
### In scope (`crates/aurora-testkit/**`)
- `TestDb::new().await -> TestDb`: connects to the server in `AURORA_TEST_DATABASE_URL` or `DATABASE_URL` (load `.env` from workspace root if present), creates a uniquely named database (`aurora_test_<uuid simple>`), runs `aurora_db::MIGRATOR`, exposes `pool()` and `url()`; `Drop`/explicit `cleanup().await` drops the database (best effort, `WITH (FORCE)`).
- If neither env var is set: start a podman container `docker.io/library/postgres:16` once per test process (random host port, wait for ready), reuse it for all `TestDb`s, and print how to set `AURORA_TEST_DATABASE_URL` to skip this. Keep this path simple and documented; it is a fallback.
- `MockUpstream`: thin wrapper over `wiremock::MockServer` with helpers: `json(method, path, status, body)`, `expect_header(name, value)`, `received()`; re-export `wiremock` for advanced use.

### Out of scope
- OAuth/OIDC mocks; gateway-specific helpers.

## Acceptance criteria
- [ ] Tests: two `TestDb`s are isolated (insert in one invisible in the other); migrations applied (a known table exists); cleanup drops the DB; `MockUpstream` serves a JSON route and records the request.
- [ ] `cargo test -p aurora-testkit`, clippy `-D warnings`, fmt check pass.

## Dependencies
- Blocked by: BE-004. Unblocks: M1 service tests.

## Suggested agent/model
haiku-worker. Escalate to rust-developer if async drop/cleanup design gets tricky.
