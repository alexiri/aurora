# FIX-066: Skill libraries — refresh has no overall bound, paused libraries stay browsable, count cap races, `over_budget` sticks (code review 2026-11-13) — **low**

## Problem
Code review of `09e955c9..bc7857ad` (P4-GSL, D-148/D-149/D-154, SEC-83/84, C-570..C-579):

1. **Refresh runs have no overall bound.** `services/aurora-api/src/domains/skill_libraries/content.rs` ~22 allows 40 busy-retries × 250 ms per gateway call; a library read is many calls (tree pages + up to 50 blobs per skill, each with a 25 s HTTP timeout) and can exceed `LIBRARY_LEASE` (5 min, `crates/aurora-core/src/limits.rs` ~120). Another replica then claims the library (work duplicated; `finish_refresh` is owner-fenced so no corruption, but `proposed` rows may be inserted twice). `refresh.rs` ~92 awaits `join_all` with no timeout, so one slow library delays the whole 60 s tick on that replica.
2. **`over_budget` can stick.** `refresh.rs` ~313: on budget exhaustion the loop `break`s but still records `last_head_sha = head`; skills not compared in this pass are skipped until the head changes. Verify and fix (do not advance `last_head_sha` on a partial pass), with a test.
3. **Paused/error libraries stay usable by members.** `list_libraries` hides non-active libraries from members (C-570), but `browse_of` (`skill_libraries/routes.rs`, used by browse and get-skill) and `skills/library.rs` `add` (~152–250) don't check status: a member with the id can browse, read and add skills from a `paused` library (pausing is the admin's stop control). Admins may still browse; members get 404 (same as list hiding) — decide against docs/10 / C-570 wording and cite it.
4. **Library count cap race.** `skill_libraries/service.rs` `create`: `count_libraries >= LIBRARIES_PER_ORG` then insert in a separate step without a lock — concurrent creates exceed 10. Use the org-keyed advisory lock pattern (`lock_budget` in skills).
5. **Duplicate `proposed` rows** (consequence of 1): add a uniqueness guard (unique index on `(skill_id, content_sha256)` for `proposed`, or an `ON CONFLICT DO NOTHING`) if a migration is cheap; else rely on the bound from 1 and say so.
