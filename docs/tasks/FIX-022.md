# FIX-022: Agent Access tab — connection grant editor (spec gap found 2026-11-09)

## Problem
`docs/14-web-dashboard.md` › agent page › **Access** has specified connection grants since phase 0:
- full, or custom with allow/ask/block per tool;
- read/write groups;
- wildcard umbrellas only where valid;

Today a connection can only be granted through the API or CLI. FIX-021 adds a basic credential-side path (full, or `custom_only` with allowed tools). This task adds the full per-agent editor.
