# FIX-125: Instance-level audit log (Admin › Audit) — **medium**

## Goal
Orgs and workspaces have an audit view (`GET /v1/orgs/{org}/audit`, `/v1/workspaces/{ws}/audit`); the
instance has none, so what instance admins do (plugin approvals, host-claim decisions, trusted keys,
connectors, runners, placement, instance freezes, OAuth clients, identity) cannot be reviewed anywhere.
Add an instance audit page that lists instance-scoped rows and can also search across orgs.

## Linked requirements
- `03 §audit_log` (`org_id` is nullable; `actor_kind` includes `instance_admin`), `04 §Audit`
  (security-critical set), `05` audit routes (RFE-008 filters `actor_id`, `action`, `critical`),
  `14 §Instance administration`.
- Owner feedback 2026-11-13: "audit log at the org level is good, should have one at instance level too".

## Scope
### In scope
- **Inventory first**: list every instance-admin write route (`/v1/admin/**` and instance-level
  freeze/OAuth-client/identity writes) and check it writes an audit row with `org_id = null` (or the
  affected org's id when it targets one org, e.g. freezing an org). Add the missing rows; mark the
  security-critical ones per `04 §Audit` (trusted-key add/revoke, plugin approve/reject, host-claim
  decision, connector manifest approval, runner token rotation) so they are written transactionally.
- `GET /v1/admin/audit` (IA): filters `scope=instance|all` (default `instance` = `org_id is null`),
  `org` (id), `actor_id`, `action` (prefix), `critical`, `since`/`until`; cursor pagination like the org
  route; same row shape plus `org_id`/`org_slug`.
- Migration: index `(created_at desc) where org_id is null` and `(created_at desc)` if `scope=all` needs it
  (check the plan with `EXPLAIN` on a seeded table).
- Page `/admin/audit`, reusing the org audit view's table/filter components (extract them into a shared
  component rather than copying), with an org column and filter in `all` scope.
- `05`, `14`, `API_CONTRACTS`.
### Out of scope
- Making `audit_log` append-only (Q-R5-23, phase 5); retention changes.

## Constraints / file ownership
api `domains/audit/routes.rs`, `crates/aurora-db/src/repo/audit.rs`, the admin write routes that lack rows,
one migration, `web/src/app/admin/audit/`, the shared audit table component (moved from the org audit
page). Coordinate with FIX-124 only on the admin nav file (one owner at a time).

## Acceptance criteria
- [ ] IT: each instance-admin write in the inventory produces an audit row (table-driven test over the
      inventory); critical ones fail the action when the row cannot be written.
- [ ] IT: `/v1/admin/audit` returns instance rows only by default, filters work, cursor pages are stable,
      non-admin → 403, org owners' org audit unaffected.
- [ ] Web test for the page and filters; 390 px, both themes, shared primitives.
- [ ] Targeted api ITs, clippy, fmt, web checks and production build.
