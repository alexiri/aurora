# FIX-200: internal-only hosts listed once, by name, in Helm (owner 2026-11-21, D-437)

## Why

Owner, 2026-11-21: "having a list of IPs in the helm chart is not scalable: I'm not going to be updating them as
DNS starts giving different IPs", then "can you add this to the current helm charts so I just have to list the
FQDNs somewhere on my-values.yaml and everything will be handled?". Production runs Cilium. The `cern-rotas` addon
needed `gateway.allowed_private: asm.cern.ch` **and** a `networkPolicy.gatewayExtraEgress` ipBlock
`172.18.201.173/32`, which breaks silently when ASM's address changes. The API (self-hosted app checks, connect
probes) and the hook host (hook egress) could not reach private hosts at all.

## Change (D-437)

- `values.yaml`: `privateHosts.names` (`[]`) and `privateHosts.ports` (`[443]`), documented in place.
- `templates/configmap.yaml`: each name must be a lower-case host name or `*.suffix` with at least two labels after
  `*.` (addresses, CIDRs, ports and schemes fail the render); the names are added to
  `config.gateway.allowed_private`, keeping the operator's own entries (deduplicated).
- `templates/networkpolicy.yaml`: with names and NetworkPolicies on, a CiliumNetworkPolicy `<release>-private-hosts`
  for the gateway, API and hook host: a DNS rule to the `dnsNamespaceSelector` namespace (`matchPattern: "*"`, only
  so Cilium's DNS proxy sees the lookups) and `toFQDNs` (`matchName`, `matchPattern` for `*.`) on the ports.
  Without `networkPolicy.cilium.enabled` the render fails with what to do instead.
- Docs: `23 §NetworkPolicy` (two rows), `15` (`gateway.allowed_private` row).
- Guard: `scripts/guards/chart-ops.sh` §privateHosts: default render has neither; the union and the policy's names,
  components and ports; NetworkPolicies off gives only `allowed_private`; no Cilium refuses; five bad entries refused;
  a self-test.

## Notes for operators

- Setting the list makes `gateway.allowed_private` Helm-managed: Administration › Limits shows it read-only. Copy
  any entries made there into `config.gateway.allowed_private` (or `privateHosts.names`) first.
- In Cilium `*` stays within one label (`*.example.org` covers `a.example.org`, not `a.b.example.org`); list deeper
  names, and a CNAME's target, explicitly.
- Remove an old per-host ipBlock from `gatewayExtraEgress` only after a request through the new policy works.

## Not in this fix

An implicit allowance for hosts an instance admin registers as self-hosted apps (no Helm edit per host): a
possible follow-up with its own decision.
