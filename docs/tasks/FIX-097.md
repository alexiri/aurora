# FIX-097: Deletion completeness — orgs with groups or SCIM rows can be deleted, deletions purge what the spec says they purge, sign-out ends preview access (REVIEW-5 PLAT-1/5, DB-1/2/4/7/8, CRED-7/8/9, CONV-3) — **high**

## Problem
1. **An org with a directory group, SCIM token or SCIM link cannot be deleted.** `crates/aurora-db/src/repo/orgs.rs` `delete_cascade` (~109–131) was not extended for phase 4: `groups`, `scim_tokens` and `scim_users` reference `organizations` with `ON DELETE RESTRICT` (`migrations/20261130000001_groups.sql`, `20261201000001_scim.sql`), so the final delete fails and the transaction rolls back. The only org-delete test (`tests/it/tenancy.rs` ~193) creates none of them, and nothing enumerates RESTRICT children (`docs/03`: restrict "so a forgotten table fails loudly").
2. **Account deletion leaves the person's direct conversations in the agent's home.** `DELETE /v1/me` → `account::delete_user` is a bare `DELETE FROM users` (`repo/account.rs` ~138); `conversations.direct_user_id` cascades in SQL, so no `session_purges` row is queued and no `conversation.delete` audit row is written (compare `repo/lifecycle.rs` `delete_conversation` ~73–110). The harness session file with the full transcript stays readable on the next resume. SEC-47: deletion includes "the harness session files in the agent's home".
3. **A superseded harness session is never purged.** `set_session` overwrites `harness_session_ref` (`repo/hosted.rs` ~331–348); deletion purges only the current ref.
4. **Sign-out does not end preview access** (coordinator-verified). `sessions::revoke` sets `revoked_at` and keeps the row (`repo/sessions.rs` ~82), so the `preview_sessions` FK cascade never fires; `find_live_preview_session` (`repo/preview_relay.rs` ~60) does not join `sessions`; `delete_preview_sessions_of_session` (~96) has no caller outside tests. A signed-out or admin-revoked session keeps resolving previews for up to 8 hours. `docs/04` ~973–977: "session row live"; "signing out or revoking the dashboard session deletes that session's preview sessions".
5. **Tenant deletion leaves secret material in Vault and the gateway warm.** Org and workspace deletion remove `secrets`, `app_connections` and `app_oauth_clients` rows without discarding their managed values (`tenancy/service.rs` ~327–350, `tenancy/routes.rs` ~553–563; single deletes do discard) and without `notify_gateway_invalidate` (`Scope::Org` exists). Agent deletion leaves grant-sourced `derived_rules` (`agents/service.rs` ~482–505).
6. **A deleted user's personal workspace becomes selectable as a shared workspace.** `personal_owner_user_id` is `ON DELETE SET NULL`; placement choices list workspaces where it is NULL (`repo/placement.rs` ~130; `placement/service.rs` ~537), so an admin can bind every newcomer to a departed person's workspace with its conversations and memory.
7. **Retention deletes inside frozen scopes.** `retention_candidates` (`repo/lifecycle.rs` ~396–410) has no freeze predicate although freeze is documented as "keeping every byte of state for forensics" (`docs/04` ~991).

## Linked requirements

## Spec change (apply with the fix)
- `docs/04` §Freeze: "retention is suspended for a frozen agent, workspace or organization; it resumes at unfreeze".
- `docs/04` §Deletion semantics: account deletion deletes the person's direct conversations through the conversation-deletion path (session purge, audit) and deletes their personal workspace when they are its only member; otherwise the workspace stays marked personal and is never offered as a shared workspace. Tenant deletion discards managed secret material and invalidates the gateway.

## Scope
- `delete_cascade`: `scim_users`, `scim_tokens`, `groups` before `organizations`; a test that reads `pg_constraint` for RESTRICT children of `organizations` (and `workspaces`) and fails when one is not handled.
- `delete_me`: delete each direct conversation through `lifecycle::delete_conversation` in the same transaction, then the user. `set_session`: queue a purge for a replaced ref.
- `sessions::revoke`, `revoke_all_for_user_except(_tx)`: delete the sessions' preview sessions in the same transaction; `find_live_preview_session` joins a live `sessions` row.
- Org/workspace/agent deletion: collect managed refs, discard after commit, invalidate the gateway, delete derived rules.
- Personal workspaces: a sticky marker excluded from choices and refused by `PUT /v1/admin/placement`; deletion rule as specified.
- `retention_candidates` excludes frozen scopes.
