# FIX-186: The agent's section switcher ends at its last tab

## Goal
Owner, 2026-11-20 (D-403). On the agent page the section switcher (**Chat · Triggers · Computer**, segmented
`Tabs`, label "Agent sections") draws its grey `bg-subtle` track well past the last tab: an empty stretch after
**Computer** up to the Agent actions (…) button. Remove it: the track ends where the last tab ends.

## Cause
`web/src/components/agents/agent-page.tsx`, the header (about line 220):

```tsx
<div className="order-3 w-full min-w-0 md:order-2 md:w-108 md:shrink">
  <Tabs … className="flex" tabClassName="max-md:min-h-11 max-md:px-1.5" />
</div>
```

The segmented strip is `inline-flex max-w-full` in `web/src/components/ui/tabs.tsx`. P5-POLISH-6 (commit 6a956f87)
added `className="flex"`, which makes the strip a block that fills its wrapper: 432 px (`md:w-108`) at md and up,
the whole row below md. The tabs are `shrink-0` and do not grow, so the rest of the track is empty.
`flex` was probably added to drop the baseline gap an `inline-flex` box leaves under itself inside a block (the
header must stay at most 64 px; `web/e2e/agent-page-p5.spec.ts` checks it). Keep that: do not go back to
`inline-flex`.

## Change
1. **md and up:** the strip hugs its tabs. Keep it a flex box but give it its content's width (`w-fit`, still
   `max-w-full`), and let the wrapper size to it (`md:w-auto md:shrink-0` instead of `md:w-108 md:shrink`), so the
   switcher sits just left of the Agent actions button with the header's usual `md:gap-x-4`. The name column keeps
   `flex-1 min-w-0` and truncates first, as today. Check 768 px, 1024 px and 1440 px: the header stays one row,
   nothing overlaps, the name truncates rather than the tabs.
2. **Below md** (the switcher is the 44 px row under the compact header): no empty tail there either. The strip
   stays full width and the tabs share it equally (each tab `flex-1`, label centred), via `tabClassName` for
   `max-md` only. A BYO agent's single tab (Computer) fills the row. If equal shares would make any label wrap or
   clip at 390 px, use a hugging strip below md as well, and say so in the report.
3. Prefer a fix in the agent page's props (`className`/`tabClassName`). Change `ui/tabs.tsx` only if a prop cannot
   do it, and then keep every other `Tabs` caller (segmented and underline, `overflow="menu"`) as it renders today.
4. Tokens and primitives only (14 §Visual design); both themes; no horizontal scroll at 390 px.
5. Docs: in `docs/14-web-dashboard.md` §Agent page, the header bullet ("on the right the **section switcher**
   (segmented `Tabs`, label "Agent sections")…"), add: (phase 5, FIX-186, D-403) the switcher is as wide as its
   tabs (no empty track after the last one); on a phone its tabs share the row equally.
