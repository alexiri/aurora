# MM-003: Target Mattermost 11.7 (production version) (phase 1, now)

## Goal
Production runs **Mattermost 11.7**. Make it the target version of `aurora-connector-mattermost`: the conformance container, the live scenario and the documentation. 12.x support is not required.

## Scope
- `scripts/mattermost/setup.sh`: pin a Mattermost **11.7.x** server image by digest (the `mattermost-preview` 11.7 tag or the official `mattermost/mattermost-team-edition:11.7.x`, whichever seeds reliably). Record the version, digest and license in `connectors/mattermost/README.md`.
- Re-run the conformance suite against 11.7 (`bash scripts/conformance.sh --mattermost`). Re-check every MM-001 quirk and every S-15 finding on 11.7. In particular, check whether `GET /api/v4/users/{id}` exposes `email_verified` to the bot or a system admin on 11.7, and whether the interactive-action and slash-command payloads differ. Adapt the connector where 11.7 differs, keeping one code path unless a version split is unavoidable.
- `docs/20-mattermost-connector.md`: state the supported version (11.7), and update S-15 in `docs/90-decisions.md` if a finding differs on 11.7.
- MM-002's live scenario runs against 11.7.

## Acceptance criteria
- [ ] Conformance passes 12/12 (or lists only the documented quirks) against the pinned 11.7 container.
- [ ] Unit tests pass; fmt, clippy `-D warnings` and guards pass.
