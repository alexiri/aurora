# FIX-289: one diff view with the same controls everywhere (owner, 2026-11-28)

## Why

Owner, 2026-11-28, comparing the memory History diff with the agent template's "About this template" diff: "all diff
views should reuse the same component, with the same controls. Those buttons should be part of it." He also asked:
"the 'Show all' button does the same thing as the 'Show the whole file' toggle, do we really need them both? Maybe the
toggle can go?" and "in the agent template update screen, the button 'Show the current text' is kind of redundant now
that we have the diff view, no?"

What is actually happening:
- Every screen already uses `web/src/components/ui/diff-view.tsx`: memory History, the template version review
  (`templates/review-version.tsx`), the update review dialog (`templates/review-changes-dialog.tsx`), and the skill
  library and skills pages.
- Only memory History passes `wrap` (P5-MEMORY-3; the hanging indent is FIX-277's). Everywhere else long lines don't
  wrap, so the table grows wider than its box and scrolls sideways.
- The fold row (`FoldButtons`: "N unchanged lines · Show N more lines above · below · Show all") is `text-center` across
  the whole table width. On a wide table it sits far to the right, out of view, so the owner saw an empty bar and no
  buttons.

## Decision (Orchestrator, agreeing with the owner)

1. **One behaviour everywhere.** Long lines always wrap, with the hanging indent, in every diff. Remove the `wrap`
   prop: no caller chooses any more. The fold row never depends on the table's width: its text and buttons sit at the
   left of the box, in view, and wrap onto a second line on a phone.
2. **Remove the "Show the whole file" switch.** Each fold's **Show all** opens that fold. Keep the "This file has N
   lines, so only the changes and their context are shown until you expand them" note for very large files.
3. **Remove "Show the current text" / "Hide the current text"** from the template version review (`PartText` in
   `review-version.tsx`). The diff, with its folds opened, is the current text and the change. An unchanged part keeps
   its **Unchanged** fold, which shows the text.

## Tests (each must fail before the fix)

- vitest (`tests/diff-view.test.tsx`):
  - a diff with a 300-character line: the fold row and its three buttons are rendered and reachable;
  - the line wraps, and no caller can turn wrapping off;
  - there is no "Show the whole file" switch.
- vitest for the template review: a changed part has no "Show the current text" button.
- Mocked Playwright:
  - the template update journey (`fix-251-template-update-journey.spec.ts`) or the template review spec, at 1280 and
    390 px: the fold buttons are visible inside the box, and the box doesn't scroll sideways;
  - memory History is unchanged.

## Tests move with the UI

Grep `web/tests` and `web/e2e` (mocked and production) for "Show the whole file", "Show the current text", "Hide the
current text" and the `wrap` prop, and update every test that uses them in the same commit. Never loosen an assertion.
