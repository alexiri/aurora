# FIX-287: shellcheck every shell script the apps ship (2026-11-28)

## Why

P5-APPSKILL-1 and P5-APPSKILL-4 added shell scripts to app skills, for example under `plugins/builtin/*/skills/**/scripts/`
(Grafana, Indico). Their reports say shellcheck "is not installed here", so it never ran. CI's guard
(`scripts/guards/run-all.sh` ~:87-90) checks only `scripts/dev` and the guard scripts. FIX-255 and FIX-274 covered dev
scripts only. A script an agent runs in its sandbox with a quoting bug is a real defect.

## Change

1. CI's shellcheck step and `scripts/guards/run-all.sh` also check every shell script under `plugins/` and
   `templates/`: files with a shell shebang, or ending in `.sh`.
2. Fix every finding, or disable it inline with its reason, as FIX-255 did.
3. For each app package whose script changed, bump the version and add a changelog entry, so agents get the fixed
   script.

## Proof

Run shellcheck through podman (`podman run --rm -v "$PWD:/mnt:ro" -w /mnt docker.io/koalaman/shellcheck:stable …`) on
every file, before and after. List the findings in the report. The app package checks (`check-builtin.sh`) still pass
for the bumped apps.

## Placement

One Sonnet lane, size S, scripts, CI config and app packages. Normal code review by the Orchestrator. Not in parallel
with FIX-286's Atlassian change if it touches the same package; check at start.

## Completion report

Done in the lane (2026-11-28). Waiting for the normal code review.

**Files**
- `scripts/guards/shipped-shell.sh` (new). It checks every file under `plugins/` and `templates/` that ends in `.sh` or
  starts with a shell shebang (`sh`, `bash`, `dash`, `ksh`). It skips `target/` and `node_modules/`. It runs
  shellcheck. Without shellcheck it only checks syntax (`sh -n` or `bash -n`), and with `CI=true` it fails instead.
  A missing directory, or one with no shell script, also fails.
- `scripts/guards/run-all.sh`: runs the new guard's `--self-test` and then the guard. Also an inline `SC1091` disable,

  is missing, the guard fails and doesn't skip.
