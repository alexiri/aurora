# BE-011: Email/password authentication flows + mailer

## Goal
Sign-up, sign-in/out, email verification, password reset/change, sign out others, in-memory auth rate limits, SMTP/log-only mailer.

## Linked requirements
- M1/04 `§Sign-up and organization creation` (signup modes), `§Email and password`, `§Sessions` (creation, cookie attributes, revocation), `§Rate limits (auth)`, `§Instance admins` (flag granted on sign-in when *verified* email is in `auth.instance_admins`); SEC-10, SEC-22, SEC-32. Contract: `docs/API_CONTRACTS.md` M1 rows `/v1/auth/*` (non-OIDC, non-CLI) + decisions C-01, C-06.

## Context
- Follow BE-010's fixed design and helpers (read `docs/tasks/BE-010.md` "Fixed design" and BE-010's report section in `docs/PROGRESS.md` / code under `services/aurora-api/src/http/`).
- Sign-up in `open` mode calls `tenancy::service::create_organization` (BE-012) with name `<display_name>'s org` in the same transaction as the user insert.
- Decisions I-10 (`lettre`), I-11 (common passwords file from SecLists — download `https://raw.githubusercontent.com/danielmiessler/SecLists/master/Passwords/Common-Credentials/10k-most-common.txt` once and commit it).
- argon2id params m=19 MiB (19456 KiB), t=2, p=1; PHC string in `users.password_hash`. Passwords 12–256 chars, not in the list (case-insensitive). Email trimmed + lower-cased.

## Scope
### In scope
- `services/aurora-api/src/domains/auth/` (routes, service, password, mailer module `mail.rs` with `Mailer` trait: `SmtpMailer`, `LogMailer` (INFO log with link), plus `MemoryMailer` for tests), repos `crates/aurora-db/src/repo/{users,sessions,email_tokens}.rs` additions.
- Routes: signup, login, logout, verify-email, verify-email/resend, password/forgot, password/reset, password/change (SO), sessions/revoke-others (SO), exactly per contract.
- Sign-up modes: `open` (anyone; creates own org); `invite_only` (only with a valid pending `invitation_token` for the same email — C-01 marks email verified — or email in `auth.instance_admins`); `sso_jit` → 403 `signup_closed`. Duplicate email → 409 `email_taken` (do not leak via timing in login; use a dummy hash verify when the user doesn't exist).
- Sessions: `aus_` token, hash stored, `expires_at = now + SESSION_ABSOLUTE` (config), cookie `aurora_session` `HttpOnly; SameSite=Lax; Path=/` + `Secure` iff external URL is https. Logout revokes + clears cookie + publishes `aurora_auth_revoked`. Reset revokes all sessions; revoke-others keeps current.
- Verification `aui_` token 24 h; reset `aui_` token 1 h; links `<external_url>/auth/verify?token=…`, `/auth/reset?token=…`. Tokens single-use (`used_at`).
- Instance-admin flag: on successful login/sign-up, if the user's email is verified and in `auth.instance_admins` (case-insensitive) set `is_instance_admin = true` (never revoke here). Update `last_login_at`.
- Rate limits per `04` (sign-in 10/min/IP and 5/min/email; sign-up 5/h/IP; reset 3/h/email) via BE-010's limiter.
- Audit: `user.signup`, `user.login` (success/failure), `user.logout`, `user.verify_email`, `user.password_reset`, `user.password_change`, `session.revoke_others`. Never log tokens or passwords.
- utoipa annotations; regenerate `web/openapi.json` + `pnpm gen:api`.

### Out of scope
- OIDC (BE-015), CLI flow (BE-014), invitations accept (BE-013), `/v1/me` (BE-016), bootstrap-admin command (BE-016).

## Acceptance criteria
- [ ] Service tests: open-mode sign-up creates user+org+workspace+Daneel and sets a cookie with the right attributes; invite_only refuses without invitation (403 `signup_closed`), accepts admin-listed email, accepts valid invitation token (email verified, invitation still pending); weak/common/short password → 400 with `details.fields[0].path == "/password"`; login wrong password → 401 `invalid_credentials`; disabled user → 403 `account_disabled`; rate limit → 429 + `Retry-After`; verify token single use + expiry; reset revokes all sessions; change requires current password and refuses API keys (403 `session_required`); revoke-others keeps current session; logout makes the old cookie 401; instance-admin flag granted only when verified.
- [ ] `cargo test -p aurora-api -p aurora-db`, clippy (`-p aurora-api -p aurora-db --all-targets --all-features -D warnings`), fmt; OpenAPI drift test; `cd web && pnpm gen:api && pnpm typecheck`.
