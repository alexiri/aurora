# FIX-026: Instance admin pages reachable from the sidebar (owner, 2026-11-10)

## Problem
The owner could not find the instance admin pages (to configure Mattermost under Admin › Connectors). The only link was in the account menu at the bottom of the sidebar, and only for instance admins; an operator who is not yet an instance admin sees nothing and has no hint how to become one.

## Done (coordinator, directly)
- `web/src/components/app-shell.tsx`: `InstanceAdminLink`, an "Instance admin" item above the theme switch on every page for instance admins (hidden on `/admin/*`, where the admin nav shows). Test `web/tests/instance-admin-link.test.tsx` (shown for admins, hidden for others and on admin pages).
- Becoming the first instance admin is documented in `docs/operator/sign-in.md` (`auth.instance_admins`, `aurora-api bootstrap-admin`, P4-IDP-1 `role_mappings` with `instance_admin: true`); `docs/operator/install-helm.md` post-install checks point to it.
