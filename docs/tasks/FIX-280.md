# FIX-280: the emergency reader walk's three leftovers (P5-MEMORY-5 pass 2, 2026-11-27)

## Why

P5-MEMORY-5 pass 2 (`docs/design/skills-memory/verify/MEMORY-REPORT-pass2.md`, "To send back") walked every workspace
page as an emergency reader on a live stack after FIX-277. Every Memory row is Match. Three things outside those rows
are left; read them there with their captures (`memory-pass2/walk-*`).

1. **W-1, broken: a reader opening a skill's file gets an error box.**
   - The skill panel's file tree lets the reader open a file, `scripts/firing.sh`.
   - The server refuses skill files to anyone without own access. This is on purpose: `route_inventory.rs` keeps "the
     skill item and its files" on own access.
   - So the request is a 403, and the panel shows "You manage this workspace but you are not one of its people.", a
     Manage link and **Try again**, which can only fail again.
   - The same happens on the workspace and organization skill panels.
2. **W-2, flow: a dead Reply on read-only conversations.**
   - Hovering a message in a conversation with no composer offers **Reply**, which does nothing.
   - It shows for the emergency reader, and also for a co-owner reading another member's direct chat, so it is older
     than FIX-277. D-470 says no control may silently do nothing.
3. **W-3, words: the manage page contradicts itself while access is open.** The notice says "Emergency read access is
   open until …" with **Read the workspace's agents**, while the Agents section below says "you cannot open them".

## Change

1. W-1:
   - For an emergency reader (`isEmergencyReader`), the skill panel lists a skill's files but doesn't open them, and no
     file request is made.
   - The tree says, in one quiet line, that emergency read access doesn't cover a skill's files. Use the words the
     other not-covered notices use.
   - The same on every skill panel: agent, workspace and organization.
   - Don't change the server: whether a reader may read skill files is a security decision for the owner, and is not
     part of this brief.
2. W-2: no Reply where the conversation has no composer, for any viewer. Copy and Copy link stay. Find the one place
   that decides "this conversation can be written" and use it.
3. W-3: while the viewer's own grant is open, the manage page's Agents sentence doesn't say the agents can't be
   opened. Say they can be read, or drop that clause.
