# FIX-126: Storage pages are served from a cached snapshot and leave the `export` rate class — **small–medium**

## Goal
Opening Admin › Storage a few times while clicking around shows "You're going fast — retrying in 30s".
Cause: `GET /v1/admin/storage` and `GET /v1/orgs/{org}/storage` are in the **`export`** rate class
(`05` rate-limit table: 6 / hour, burst 2), because each call recomputes the numbers live
(`services/aurora-api/src/domains/attachments/storage.rs::admin_storage`: blob totals, usage totals, file
counts, top orgs with one `org_limits` query each, `pg_total_relation_size` per big table). A page view must
never be rate-limited like a conversation export. Serve the numbers from a cached snapshot and put the
read routes in the ordinary `general` bucket.

## Linked requirements
- `05 §Rate limiting` (class table), `05 §Background jobs` (the daily attachment sweep reconciles
  `org_storage_usage`), `10 §Attachments`, `14 §Instance administration` (Storage page).
- Owner feedback 2026-11-13: "just 6 per hour is ridiculous! Storage usage should just be cached".

## Scope
### In scope
- A storage snapshot persisted in the database (all API replicas share it): instance breakdown and per-org
  figures with `computed_at`. Computed by the daily attachment sweep, and lazily when absent or older than
  a bound (e.g. 1 h; add the constant to `aurora-core::limits` and `02 §Limits`), with a single-flight guard
  so concurrent requests do not all recompute. The org quota figure (`used_bytes`, `notice`) keeps coming
  from the live `org_storage_usage` counter (it is one row and must stay exact for quota notices).
- Both GET routes move to the `general` class and return `computed_at`.
- `POST /v1/admin/storage/refresh` (IA) and `POST /v1/orgs/{org}/storage/refresh` (org owner/admin) to
  recompute on demand; these stay in a strict class (the `export` class is fine for a deliberate button).
- Web: show "Updated <relative time>" and a **Refresh** button (disabled with the retry time on 429);
  set a sensible `staleTime` on the two hooks in `web/src/lib/api/org.ts` so navigating back does not refetch.
- Check the rest of the `export` class and every other strict class for other **plain page reads** that
  would hit the same wall; list any in the completion report (fix only if trivial and same pattern).
- `05` table and route catalogue, `14`, `API_CONTRACTS`, `docs/operator/retention-and-quota.md`.
### Out of scope
- Changing the general/org bucket sizes; the rate-limit notice component.
