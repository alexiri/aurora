# FIX-031: Nightly `sandbox-base-smoke` is red — the sandbox image has no `rpm` binary, so the base-image override smoke can never compare package lists

## Problem

The nightly job `sandbox-base-smoke` (`.github/workflows/nightly.yml:119-125`, `SMOKE_FULL=1 bash scripts/images/sandbox-base-smoke.sh`) has **never been green**: run 42946111582 (2026-11-11) failed with exit 127, `crun: executable file 'rpm' not found in $PATH: OCI runtime attempted to invoke a command that was not found`.

- `scripts/images/sandbox-base-smoke.sh:61-62` (and the SMOKE_FULL=1 twin for the full target) compares the installed package lists of the two built images with `podman run --rm --entrypoint rpm <image> -qa --qf '…'`. The script exists to prove the P3-019 invariant (a `SANDBOX_BASE_IMAGE` override changes where the base comes from, never what the image contains — docs/18 §Deployment-neutral defaults; AUDIT-003 F-9).
- `images/sandbox/Containerfile` `os` stage (line 43) installs `shadow-utils glibc-common postgresql` with `--setopt=install_weak_deps=False` — the `rpm` binary is not in that list and not guaranteed by any of them on the pinned AlmaLinux 10 base (`ARG SANDBOX_BASE_IMAGE=…almalinux:10@sha256:5a4b41a4…`). The build succeeds; only the later `--entrypoint rpm` invocation fails.
- Effect: a red nightly every run, obscuring real nightly regressions, and the deployment-neutral-defaults invariant (a mirror/override base must produce an identical image) is not actually being verified.

## Goal (priority: **high** — red nightly gate, size: **S**)

The sandbox image ships the `rpm` binary so the smoke script's package-list comparison works; the nightly `sandbox-base-smoke` job goes green.

## Scope

It must be present in every target built from that stage (`base`, `sandbox`, `sandbox-min`) because the smoke compares both `sandbox-min` (default) and the full `sandbox` target (`SMOKE_FULL=1`).
2. Nothing else changes: `org.aurora.capabilities` labels, users, paths, the supervisor build, the chromium-wrapper — untouched.

## Addendum (coordinator, 2026-11-11): finishing SMOKE_FULL — the `base` stage's rpm deletion is deliberate and must stay

The nightly job runs `SMOKE_FULL=1` (the full `sandbox` target), and that target inherits the
`base` stage whose last RUN line deliberately deletes the agent-facing binaries:

```dockerfile
# No privilege escalation or package management for the agent.
&& rm -f /usr/bin/sudo /usr/bin/su /usr/bin/dnf* /usr/bin/yum /usr/bin/rpm* 2>/dev/null; true
```

That deletion is a RUN-003 security invariant (the agent never gets package management or
privilege escalation) — **do not undo it**. Instead, make the smoke comparison work without an
in-image `rpm` binary:

1. `scripts/images/sandbox-base-smoke.sh` — the container doing the comparison does not need the
   image's own `rpm`: the `os` stage (fixed above) has the binary, and the full image keeps the
   `librpm*` libraries (only `/usr/bin/rpm*` are deleted). Extract the binary from the freshly
   built os-stage image and bind-mount it into the image under test:
   - also build the `os` target once per `compare_target` run (layer-cached, near-free):
     `podman build -q -f "$cf" --target os -t "$prefix-os" .`
   - extract: `podman create --name "$prefix-extract" "$prefix-os" true && podman cp "$prefix-extract":/usr/bin/rpm ./rpm-extract && podman rm -f "$prefix-extract"`
   - compare with: `podman run --rm -v ./rpm-extract:/usr/bin/rpm:ro --entrypoint /usr/bin/rpm "$img" -qa --qf '…'`
   - clean up `./rpm-extract` and the `os` tag in the trap; keep the script's own lock-free
     single-run assumption (it takes no lock; do not add one).
2. If the bind-mounted binary fails to start (missing librpm symbol or loader path), bind-mount the
   needed `/usr/lib64/librpm*` (+ `librpmio*`, `libpopt*`) from the extract container too — still no
   change to the shipped image. If that also fails, stop and report; do not switch the comparison
   mechanism on your own.
3. Everything else from the original spec stands. The proof for this addendum is
   `SMOKE_FULL=1 SMOKE_PREFIX=aurora-fix031 bash scripts/images/sandbox-base-smoke.sh` passing both
   targets (expect longer wall time; Chromium pulls are network-bound). Record both mode results.
