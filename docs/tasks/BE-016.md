# BE-016: /v1/me, admin users, bootstrap-admin, account deletion

## Goal
Profile endpoints, instance-admin user management, bootstrap command for first install, account deletion semantics.

## Linked requirements
- M1/04 `§Instance admins` (bootstrap-admin, `admin revoke`), `§Deletion semantics` (account), `05 §Auth and account` (`/v1/me`), `§Instance administration` (users); SEC-21, SEC-32. Contract: `docs/API_CONTRACTS.md` M1 rows `/v1/me`, `/v1/admin/users*` (C-04).

## Scope
### In scope (`services/aurora-api/src/domains/{me,admin}/`, `services/aurora-api/src/main.rs` subcommands, repos as needed)
- `GET /v1/me` (`Me` shape: memberships include suspended ones with status; workspaces listed per membership are those the user can use — none when suspended), `PATCH /v1/me` (`display_name` 1–80; `default_org_id` must be an active membership → else 404), `DELETE /v1/me` (SO; requires `password` for users with a password — 403 `reauthentication_required` if missing/wrong; SSO-only users: allowed if the session was created by OIDC within 10 min (use `sessions.created_at`; if no way to know the session's method, require password-less SSO users to re-sign-in within 10 min — document); refused 409 `last_owner` if the user is the last active owner of any org; deletes memberships, bindings, sessions, keys, identities; `direct` conversations with that user are removed by FK cascade). Publish `aurora_auth_revoked {kind:"user"}`.
- `GET /v1/admin/users` (IA; `q` filters email/display_name ILIKE; pagination), `PATCH /v1/admin/users/{id}` (`is_instance_admin`, `disabled` → sets/clears `disabled_at`; disabling revokes the user's sessions and publishes revocation; self-modification → 422 `cannot_modify_self`). Audit `admin.user_update`.
- CLI subcommands: `aurora-api bootstrap-admin --email <e>`: create (or update) a verified instance-admin user without password and print a one-time password-set link (`<external>/auth/reset?token=aui_…`, reset token 1 h — reuse BE-011's email_tokens repo); `aurora-api admin revoke <email>`: clear the flag. Both validate config like `migrate`.
- utoipa; regenerate `web/openapi.json` + `pnpm gen:api`.

### Out of scope
- Org/workspace deletion (BE-012), channel links on `/v1/me/*` (M6).
