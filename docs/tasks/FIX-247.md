# FIX-247: the template review shows what changed against the version people use now (owner 2026-11-26)

## Why

Owner request 2026-11-26: "when reviewing a new agent template, it would be very useful to see the diff with
the current version, so it's easier for the admin to judge." The review page (C-1114) shows the whole version
first and the diff against the current version below it, and that diff covers only instructions, skills,
helper files and memories — none of the other parts a version carries (name, summary, README, the agent's
name and `may_message_first`, effort, skill references, memories, automations, apps, inputs, `min_core`,
avatar). An administrator must read two full versions side by side to judge the rest.

## Fix

1. **A pure diff** (`web/src/lib/template-diff.ts`): diffs two `TemplateContentView`s into a typed list of
   changes covering every part, each with added/removed/changed, the part label in the product's words
   (`14 §Vocabulary`), old and new text for text parts, and a flag for the changes that widen what the agent
   can do or reach (a new or widened app, a new automation, a new library skill reference, a new helper file,
   a changed input, a raised `min_core`). It also builds the one-line summary and the list of unchanged
   parts. The apps/automations/skill_refs/inputs stored shapes (C-1104, passed through as stored) get proper
   TypeScript types in `web/src/lib/api/agent-templates.ts`; the backend already sends everything the diff
   needs, so no Rust change.
2. **The review page**: the diff comes first, under "What changed since <current version>", with the summary
   line in words, a "Look at these first" block (a labelled region) for the widening changes, then every
   other changed part with the whole-line diff (the shared `Lines` renderer), and the unchanged parts
   collapsed as "Unchanged: Instructions, Skills (3)…". First version: "This is the first version: nothing to
   compare with." Identical: "Nothing changed: this version matches <current version>." Reviewing the current
   version itself shows no diff. The full content stays below, unchanged; the decision buttons stay where
   they are. Wording from `14 §Vocabulary`; both themes; 390 px without horizontal scroll (long diffs scroll
   inside their own box); keyboard reachable; labelled headings and landmarks; axe clean.

## Proof

- vitest for the pure function: every part kind and change kind, identical content, a skill renamed, apps
  reordered (not a change), whitespace-only changes (shown), very large text, the attention flags and the
  summary words.
- vitest for the review page: the order (diff before content), the summary words, the attention block with a
  new app and a new webhook, the unchanged list, first version, identical, the current version itself.
- One mocked Playwright spec: the administrator opens the review of 1.4.0 against 1.3.0 from the Overview,
  sees the summary, the attention block and the diffs, approves; 1280 px and 390 px, both themes, axe clean.
