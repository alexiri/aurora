# BE-010: API server foundation (state, errors, extractors, auth, authz, OpenAPI, audit)

## Goal
The shared HTTP foundation every M1+ domain module plugs into, so domain tasks can run in parallel without re-deciding auth, errors, pagination or OpenAPI.

- M1/05 (`05 §Internal structure`, `§Authentication surfaces`, `§Request scoping`, `§Conventions`), M1/04 (`§Sessions` incl. CSRF and 30 s cache, `§API keys`, `§Rate limits (auth)`, `§The access law`, `§Audit`), SEC-10, SEC-21, SEC-22, SEC-29, SEC-32. Contract: `docs/API_CONTRACTS.md` (Conventions + M1 section).

## Fixed design (all later API tasks follow it)
- Layout: `services/aurora-api/src/{app.rs (AppState, router assembly), openapi.rs, http/{mod,error,json,pagination,auth,csrf,client_ip,ratelimit}.rs, audit.rs, domains/<domain>/{mod,routes,service}.rs}`. Repositories: `crates/aurora-db/src/repo/<domain>.rs` (SQL lives there, `02 §Coding rules`). Access law: `crates/aurora-db/src/authz.rs` (`04`: "implemented once in aurora-db::authz").
- `AppState { pool, config: Arc<ApiConfig>, rate_limiter, session_cache, … }` — `Clone`, cheap.
- Router: `utoipa_axum::router::OpenApiRouter`; each domain exposes `pub fn router() -> OpenApiRouter<AppState>`; `app.rs` merges them under `/v1`. Every handler has `#[utoipa::path]` with request/response schemas (`ToSchema`) matching API_CONTRACTS exactly (field names, nullability: `Option<T>` serialized as `null`, never skipped).
- `aurora-api openapi [--out path]` subcommand prints/writes the document; a test asserts `web/openapi.json` equals the generated document (`UPDATE_OPENAPI=1` rewrites it). `GET /v1/openapi.json` serves it.
- Errors: handlers return `Result<T, ApiError>`; `From<DbError>` maps not-found→404, unique violation→409 `conflict` (domain code where known), others→500 `internal` (logged, no detail leak). JSON extractor `http::json::Json<T>` maps body rejections to 400 `invalid_request` with `details.fields`; same for `Query<T>`. Require `Content-Type: application/json` on JSON bodies (415 → use 400 `invalid_request`).
- Pagination: `PageParams { limit (default 50, max 200), cursor }`, cursor = base64url(JSON `{"t": created_at, "id": uuid}`); helper builds `Page<T> { items, next_cursor }` from `limit+1` fetch; order `created_at desc, id desc`.
- Auth (`http::auth`): extractors
  - `Caller` (S or K): `Authorization: Bearer` with an Aurora prefix commits to key auth (`auk_`/`auo_` only here; other prefixes → 401); failure 401 `unauthenticated`, never falls back to cookies. Else cookie `aurora_session` (`aus_`): lookup by `sha256` hash, check `revoked_at`, idle (`last_seen_at` + `SESSION_IDLE`/config) and absolute expiry, user not disabled; update `last_seen_at` at most once/minute (churn column). Keys: not revoked/expired, owner is an **active** member of the key's org (dead otherwise); update `last_used_at` ≤ once/min.
  - In-process cache ≤30 s keyed by token hash for both sessions and keys; flushed on `aurora_auth_revoked` NOTIFY (`{kind, id}`), and fully on listener resync.
  - `SessionCaller` (SO): API key → 403 `session_required`.
  - `InstanceAdmin`: session caller with `is_instance_admin` → else 403 `instance_admin_required`.
  - `Caller` exposes `user_id`, `principal` (Session{id} | ApiKey{id, org_id, workspace_id: Option}), `audit_source` (`dashboard` for session, `api` for key), `ip`.
- CSRF (`http::csrf`): middleware for cookie-authenticated unsafe methods: `Origin` must equal the origin of `server.external_url` or be in `auth.trusted_origins`, else 403 `csrf_rejected`. Requests authenticated by bearer key are exempt. Missing Origin on unsafe cookie request → reject.
- Client IP: rightmost-untrusted from `X-Forwarded-For` when the peer is in `server.trusted_proxies`, else the socket peer.
- Rate limiter: in-memory token buckets keyed (bucket name, key) with the `04` quotas; 429 `rate_limited` + `Retry-After`.
- Authz (`aurora_db::authz`): `org_membership(pool, user, org) -> Option<{role, status}>`; `workspace_access(pool, user, ws) -> Option<WorkspaceAuth { org_id, org_role, effective_ws_role: owner|member }>` implementing the access law (suspended ⇒ none); `can_use`, `can_own`. API layer (`http::auth`) adds key confinement: workspace key on another workspace → 403 `workspace_mismatch`; org key on a workspace of another org → 404; key permissions = owner's current permissions ∩ key scope. Helpers return 404 when the caller cannot see the resource, 403 `forbidden` when visible but insufficient (`05 §Request scoping`).
- Audit (`audit.rs`): `audit::record(&state, AuditEvent { org_id, workspace_id, actor (from Caller or system), action: "entity.verb", target_kind, target_id, outcome, metadata })` — best effort: spawn/insert, log on failure, never fail the action; metadata must not contain secrets.
- Instance domain: `GET /v1/instance` per contract (version from `CARGO_PKG_VERSION`; `email_delivery` = smtp if `email.smtp_url` set else log; `setup_errors` = [] for now).

## Scope
### In scope
- Everything in "Fixed design", `GET /v1/instance`, `GET /v1/openapi.json`, `openapi` subcommand, `web/openapi.json` regenerated + `cd web && pnpm gen:api` run so `schema.d.ts` matches.
- Repos needed by auth: `repo::sessions` (create, find_by_hash, touch, revoke, revoke_all_for_user_except), `repo::api_keys` (find_by_hash, touch), `repo::users` (find_by_id, find_by_email), plus `authz`.
- Test support in `services/aurora-api/tests/common/mod.rs`: build app with a `#[sqlx::test]` pool, helpers to insert user/org/workspace/membership/session/key rows directly via SQL and to make requests (`tower::ServiceExt::oneshot`) with cookie/Origin/bearer.

### Out of scope
- Sign-up/login and every other domain route (BE-011..BE-016).

## Acceptance criteria
- [ ] Tests: session cookie auth (valid, revoked, idle-expired, absolute-expired, disabled user); key auth (valid; revoked; owner suspended ⇒ 401; bearer with bad key never falls back to a valid cookie); SO extractor refuses keys with 403 `session_required`; CSRF: cookie POST without/with wrong Origin → 403 `csrf_rejected`, trusted origin ok, bearer exempt; access law matrix (owner/admin implicit, member with/without binding, suspended ⇒ none); workspace key on other workspace → 403 `workspace_mismatch`; pagination cursor round trip; JSON rejection → 400 `invalid_request` with `details.fields`; rate limiter returns 429 with `Retry-After`; NOTIFY `aurora_auth_revoked` flushes the cache (revoked session rejected immediately).
- [ ] `GET /v1/instance` matches contract; OpenAPI drift test passes; `pnpm gen:api && pnpm typecheck` in `web/` pass.
- [ ] `cargo test -p aurora-api -p aurora-db`, `cargo clippy --workspace --all-targets --all-features -- -D warnings`, `cargo fmt --all --check` pass.
