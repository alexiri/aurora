## Scope notes
- Password sign-up/sign-in/verify/reset are removed from the product. The phase-1 migration clears `password_hash`: an additive-safe data change, but irreversible for that column's data, so confirm with the coordinator through `ask` before running it against anything but test databases (the migration file itself is fine to write). Account deletion requires OIDC re-auth.
- `bootstrap-admin` pre-provisions a user that binds at first OIDC sign-in.
- Tests and e2e harnesses must create sessions through the dev IdP / mock OIDC flow, or through a **test-only** helper that is compiled out of release builds. A test-only bypass must never be reachable in a production binary; prove that with a test or guard.
- The dev IdP is refused on a non-loopback https URL, per the spec.
- E2E: `m1.sh`, `gateway.sh`, `hosted.sh`, `channels.sh` and `llm.sh` all pass. This lane touches every harness, so start it when few other lanes are mid-flight in the same helpers.
