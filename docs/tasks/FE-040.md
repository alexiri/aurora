# FE-040: Agent Chat tab + Computer tab (hosted agents)

## Linked requirements
- M4/14 `§Workspace → Agents → agent page` **Chat** (direct conversation; other conversations in a sidebar; SSE transcript with delta rendering, tool cards, inline approvals (approve/deny using the M2 approvals API), attachments shown as links (upload is M5), follow-ups with "Send now", Stop, live activity line, door chips, error copy with deep-link fixes e.g. `no_model_key` → LLM keys page) and **Computer** (sandbox state, "awake because…" reasons, processes, restart); `14 §Key flows` → **Agent chat resume** (fetch events after last seq, then re-open the stream; discard a turn's deltas once its durable `text` arrives); `14 §Architecture rules` (untrusted text via safe markdown — reuse FE-030's renderer; never `dangerouslySetInnerHTML`). ## Scope (`web/src/**`, `web/tests/**`; don't edit generated files)
- Chat tab: get-or-create direct conversation; conversation list sidebar (kinds); transcript view rendering every durable event type of `10` (unknown types ignored); deltas from SSE (`EventSource` with `Last-Event-ID` resume; ephemeral events have no id); composer posting messages (202 turn or follow-up), Stop (abort), Send now; approval cards for `approval.pending` events with approve/deny; activity line; error mapping (known codes → copy + link; unknown → generic).
- Computer tab (hosted agents): `GET /v1/agents/{agent}/sandbox`, restart button with confirmation, processes table, keep-awake reasons, "restart to update" notice.
- Instructions tab: model picker from `GET /v1/agents/{agent}/models` (replace the disabled fields from FE-023).
- vitest: event reducer (history + stream merge, delta discard on durable text, dedupe by seq, unknown types ignored), resume logic, composer follow-up vs turn handling, approval card actions, error code mapping.
