## Problem
The REVIEW-5 lanes merged with these items recorded as open (`docs/PROGRESS.md` rows FIX-087, FIX-101, FIX-108, FIX-114, FIX-118, and the CI log of run 43553844980):

1. **`aurora logout` cannot revoke the CLI key** (FIX-118 item 7; D-188 d). The device-flow login stores an API key whose id the CLI does not know, and no route revokes "the key this request is authenticated with". Logout deletes the local file and says it did not revoke the key: the key stays valid until its TTL (`auth.cli_key_ttl_days`, 90, D-183).
2. **Role-claim memberships vs the FIX-108 removal marker.** `docs/03` (§`org_member_removals`, FIX-108/D-183) says the marker is deleted "by the next `org_members` insert for the pair (invitation acceptance, admin add, claim, SCIM)"; the FIX-108 lane reported that memberships created by **role-claim sync** do not clear it. Either the code or the document is wrong — decide from `docs/04` (JIT section, ~226: "a membership removed by an admin is not restored by JIT") and make them agree.
3. **SCIM: no test that a store that is `Closed` refunds exactly once** (FIX-087 open item; `scim/rate_limit.rs`, the counter store's closed path).
4. **Vault-backed suites skip silently outside the vault job** (FIX-101 open item): `services/aurora-api/tests/it/secrets_migrate.rs` (~393) and `crates/aurora-secrets/tests/it/support.rs` check `AURORA_TEST_VAULT` by hand and `eprintln!` "skipped" instead of `aurora_testkit::require_or_skip` (D-198), so CI cannot tell a skip from a pass.

Find the screen (run `pnpm exec playwright test --project=mocked` locally with the browser console captured), fix the component (a missing guard) or the mock (a response shape the API never sends) — whichever is wrong per `web/openapi.json`.
