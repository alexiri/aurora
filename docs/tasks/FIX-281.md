# FIX-281: the emergency reader's agent Skills page doesn't claim nothing is inherited (P5-SKILLS-5 pass 2, 2026-11-28)

## Why

P5-SKILLS-5 pass 2 (`docs/design/skills-memory/verify/SKILLS-REPORT-pass2.md`, D-1, captures
`skills-pass2/skill-1-reader-*`):
- On an agent's Skills page, an emergency reader sees only the agent's own skills. That is right: the grant doesn't cover
  the effective set.
- But the page still offers the chips **From the workspace 0** and **From Acme 0**, and a column **For Daneel**. That
  reads as "no workspace or organization skill applies to this agent", while for the same agent seven do.

## Change

For an emergency reader (`isEmergencyReader`, the agent page's `readOnly`), the agent Skills page:
- shows no chips or columns for sources it can't read;
- says in one quiet line that emergency read access shows only <agent>'s own skills, using the words of the other
  not-covered notices.

Don't change what the server allows.
