# P3-013: BYO agent-token maximum age and token use tracking (RFE-013, D-60, SEC-53)

## Goal
An optional maximum age for BYO agent tokens: instance-wide `governance.agent_tokens.max_age_days`, which an org may tighten. It is applied at mint (`expires_at`), and retrofitted to existing tokens with a 7-day grace when introduced or lowered. The gateway and API refuse expired tokens with `agent_token_expired`. `last_used_at` tracking feeds stale and expiring lists, with badges in the dashboard. **SEC-53** must be proven.

The wire behaviour is **C-310..C-317** in `docs/API_CONTRACTS.md` (API-P3): governance doc/effective/instance fields, `expires_at` on mint and regenerate, 401/407 `agent_token_expired` (and FATAL `28P01` on the database lane), the paged agent-token list routes, `Agent.byo.token`, the retrofit and its system audit row, `last_used_at`, and config. Read them first. If anything is missing, ask through Orca `ask`.
