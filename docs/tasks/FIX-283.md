## Completion report

All five items and the three small observations are done, web only. No routes, DTOs or Rust changed.

**Changes**

- **C-2:** `GET /v1/workspaces/{ws}` and `/v1/resolve` carry no `personal_of`. The record now takes "yours" from the
  `/v1/me` membership (`components/app-shell.tsx`). A record written before this change is corrected on the next
  workspace page.
- **C-3:** `backLink` (`lib/nav/manage-return.ts`) gets the recorded workspace's answer and uses `isEmergencyReader`.
  The shell (`useRecordedReading`) asks again on each page of the place, so a grant that ran out by itself is noticed
  too. A failed read counts as ended. Until there is an answer, the line is hidden. A tab left on one page after the
  grant runs out keeps the line until the next page or React Query's own refetch.
- **C-4:** `useRevealCurrent` scrolls only the rail's menu to the `aria-current` entry. It keeps doing so while the
  menu and foot fill in, and stops once the person touches the menu. The foot is as drawn.
- **C-1:** `library_update` and `org_account_broken` rows show the server's title, detail and link, with the page name
  in front of the detail. They end in **Review** (amber) or **Failed** (danger) as in `after/nav-3b.png`, with no
  button. The title and detail sentences are the server's (FIX-282).
- **C-5:** New workspace shows when the person manages the organization, or their active membership has
  `can_create_workspaces`.
- **Small items:** no second full stop after a reason that ends in `.`, `!`, `?` or `…`; the picker's search lists
  workspaces by organization name; Internet access asks for activity only where `my_role` is set or the viewer is an
  emergency reader. When some are left out, it says "From the workspaces you can read." This sentence is new: without
  it, a partial list would look like the whole organization's.
- **Local types (until FIX-282 merges, marked in the code):** the two attention kinds (`lib/api/attention.ts`) and
  `can_create_workspaces` (`lib/nav/places.ts`). After the merge, regenerate `schema.d.ts` and remove them.
