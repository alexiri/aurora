# FIX-211: App icons at 64 px everywhere (owner 2026-11-21)

## Why

The owner: "app icons are kind of tiny, make them all `size-16` instead of `size-8`." Most app icons are drawn at 32 px
(`size-8`): the App step's tiles in **Give <Agent> an app**, account rows/cards, the free-apps list, the organization's
apps list and table, Administration's packages list and sign-in gaps, and the connector icons. Apps cards ask for 36 px
(which is not in the size map and falls back to 40), a package's detail page 40, an app's setup page 48. The built-in
icons are 256 × 256 PNGs (`plugins/builtin/*/assets/icon.png`, `icon-dark.png`), so 64 px stays sharp on 2× screens.

No decision, contract or API change: `docs/14` §Visual design lists no app-icon size; this fix adds one line.

## Change (web only)

1. **`components/ui/app-icon.tsx`**: add `64: "size-16 text-2xl"` to `SIZES` (the monogram's letter scaled with it; pick
   the text size that matches the 40/48 steps' proportion and say which) and make **64 the default** `size`.
2. **Every app icon is 64 px.** Change every `<AppIcon size={…}>` (and `ConnectorIcon`'s default and its one `size={32}`
   caller, `components/connectors/shared.tsx:~131–141`) to 64 or to the default. On 55b1bdb8 the callers are:
   `accounts/free-apps.tsx:39`, `accounts/account-row.tsx:170`, `admin/plugins-view.tsx:222`,
   `admin/plugin-detail-view.tsx:179` (40), `admin/sign-in-gaps.tsx:102,160`, `apps/org-apps-list.tsx:182`,
   `apps/apps-tab.tsx:94` (36), `apps/app-setup/app-setup-page.tsx:84` (48), `apps/connect-journey/app-step.tsx:45,56`,
   `apps/org-apps-table.tsx:217`. Re-check with `rg -n "<AppIcon|ConnectorIcon" web/src` before starting; any caller
   added since gets 64 too. Remove the sizes nobody uses from `SIZES` only if no other component (e.g. `Avatar`) shares
   the map.
3. **Make the bigger icon sit well** where it lives, without changing what each place shows:
   - **Tiles** (App step) and **cards** (Apps, and Accounts once P5-LAYOUT-2 lands): icon above or beside the name as
     today; the tile's `min-h-24` grows as needed; text stays centred / aligned.
   - **Rows and tables** (org apps table, Administration packages, sign-in gaps, account rows on an agent's Access tab):
     the icon is vertically centred against the row's text block; the row grows to fit, no overlap, no clipping. In a
     `ResponsiveTable`'s stacked phone layout the icon stays at the card's start.
   - **The AI key tile** (`components/ui/ai-key-tile.tsx`, shown in place of an app icon on AI key rows) matches 64 px
     so AI keys and apps line up in the same list.
   - At 390 px, a row's text keeps at least half the width beside a 64 px icon; if it cannot, the text wraps below (as
     the account row's phone layout already does), never shrinks the icon.
4. **`docs/14`** §Visual design, components list (AppIcon): "App icons are 64 px (`size-16`) everywhere; the monogram
   tile follows the same size" (with "(owner 2026-11-21, FIX-211)").
