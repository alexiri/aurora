# FIX-100: Dashboard — Directory sync, groups and skill-library screens match the contract (REVIEW-5 WEBO-1/2/3/4/7/8/9/10/11/14) — **high (items 1–2)**

## Problem
1. **Re-authentication cannot be completed from the Directory page.** On 412 `reauth_required` the page says "sign in again with your provider" and renders the URL only in a hidden `<span data-testid="scim-reauth-url">` (`web/src/components/org/directory-view.tsx` ~100–104, ~318–320, ~367). The form always sends `enabled`, `email_domains` and `exclusive`, and the server requires a fresh re-auth for any of them (`services/aurora-api/src/domains/scim/management.rs` ~161 — stricter than C-472, which names enabling only), so every save after ten minutes dead-ends. `docs/14` §Directory sync: "turning it on opens the re-authentication step".
2. **Only the first 50 library skills can be added.** `components/skills/library.tsx` (~357, ~419) renders one page; `lib/api/skill-libraries.ts` (~94–107) accepts a cursor no caller passes; C-571 pages by 50 with `next_cursor` and sets `truncated` only past 200.
3. SCIM token revoke is immediate (`directory-view.tsx` ~217; `docs/14`: "revoke with a confirm").
4. Unbinding a group from one workspace shows the impact of deleting the whole group: `useGroupImpact(g.id, null, …)` (`groups/group-detail.tsx` ~391; `settings/group-access.tsx` ~33) — C-464 has no unbind scenario.
5. Directory-managed members keep an editable role select (`org/members-view.tsx` ~49–52; `docs/14`: role control disabled "where SCIM owns the state").
6. Group PATCH 409 shows the policy message and the stale revision is never refreshed (`lib/api/errors.ts` ~70; `group-detail.tsx` ~47, ~78); Delete is offered for SCIM-managed groups the server refuses (~435; C-461).
7. The start-diagnostics query fires with an empty agent id for every expanded runner (`admin/runners-view.tsx` ~95–100, ~218).
8. Directory page vs `docs/14`: the nav entry is shown to admins and when `scim.enabled` is off (`app-shell.tsx` ~284, ~309); the token form renders while SCIM is disabled; the status card shows 5 errors, not 20 (C-479); no copy dialog with the "cannot be shown again" sentence; no 14-day expiry banner; no copy button on the base URL; no per-IdP setup guide link.
9. The created SCIM token stays in component state and the mutation cache after it is shown (`directory-view.tsx` ~125; `lib/api/scim.ts` ~126).

- `docs/14`/C-477: whether changing the role of a SCIM-provisioned member is refused by the server (409 `managed_by_scim`) or only discouraged in the UI is owner question Q-R5-19; until answered, the UI disables the control and the server is unchanged.
