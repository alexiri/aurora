# FE-001: Scaffold the Next.js dashboard (`web/`)

## Goal
A production-buildable, empty dashboard app with the pinned tooling so later FE tasks only add pages.

## Linked requirements
- M0/14 (scaffold), `02` Dashboard line, `14 §Architecture rules`, D-31/D-32 (same origin, pure API client), I-08.

## Context (read only these)
- `docs/14-web-dashboard.md §Architecture rules` (short).
- Pinned stack (`02`): Next.js **App Router**, TypeScript `strict`, **pnpm** (`~/.local/bin/pnpm`, v10), Tailwind CSS, shadcn/ui, TanStack Query, `openapi-typescript` + `openapi-fetch` generated from the API's OpenAPI document, Playwright e2e; component tests with vitest (`18`).
- Node is **v20.20** locally: choose versions that support Node 20 (check `engines`); record chosen versions in your report.
- Dashboard port 4100 (`01 §Components`); edge routes `/v1/*` to the API on the same origin, so API calls are relative `/v1/...`. For local dev without the edge, Next `rewrites` `/v1/:path*` → `process.env.AURORA_API_URL ?? "http://127.0.0.1:4101"` (dev only is fine).
- Untrusted text rule (`02 §Untrusted text`): never `dangerouslySetInnerHTML`; markdown rendered with raw HTML disabled — add an ESLint rule (`react/no-danger` = error).

## Scope
### In scope (`web/**` only)
- `pnpm create next-app`-equivalent with App Router, `src/` dir, TS strict, ESLint, Tailwind; `output: "standalone"`; `package.json` scripts: `dev` (port 4100), `build`, `start` (port 4100), `lint`, `typecheck` (`tsc --noEmit`), `test` (vitest run), `e2e` (playwright), `gen:api` (`openapi-typescript openapi.json -o src/lib/api/schema.d.ts`).
- `web/openapi.json`: minimal valid OpenAPI 3.1 placeholder (`/v1/instance` GET returning an object with `version: string`) until the API generates the real one; generated `src/lib/api/schema.d.ts` checked in.
- `src/lib/api/client.ts`: `openapi-fetch` client (`baseUrl: ""`, `credentials: "same-origin"`), plus an `ApiError` class parsing the envelope `{error:{code,message,details}}`.
- `src/app/providers.tsx` (client component) with TanStack Query provider; root layout uses it; a placeholder home page ("Aurora") server component.
- shadcn/ui initialised (`components.json`, `src/lib/utils.ts`, one component e.g. `button`) — no unnecessary components.
- vitest + @testing-library/react config with one passing test (e.g. `ApiError` parsing); Playwright config (baseURL `http://127.0.0.1:4100`) with one smoke spec (home renders) — Playwright browser install is NOT required for this task (do not run e2e).
- `.gitignore` additions inside `web/` as needed; `pnpm-lock.yaml` committed.

### Out of scope
- Any real page, auth, layout shell (M1 FE tasks). Containerfile (OPS-003).
