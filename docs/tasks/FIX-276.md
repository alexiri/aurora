# FIX-276: the design system's own text sizes survive class merging (badges at 11 px, not 14 px) (2026-11-27)

## Why

The P5-SKILLS-3 lane found that every `Badge` renders at 14 px instead of the `text-label` size (11 px).
- `web/src/lib/utils.ts` `cn()` is `twMerge(clsx(...))` with the default configuration.
- `tailwind-merge` doesn't know the theme's own font sizes `--text-label` and `--text-micro` (`web/src/app/globals.css`
  ~:147-148). It reads `text-label` as a text **colour**.
- When a tone or the caller adds a real colour (`text-ink-2`, `text-pending-ink`, …), `twMerge` drops `text-label` as a
  conflicting colour. The badge falls back to the inherited 14 px.
- The same can happen to any primitive that pairs `text-label` or `text-micro` with a colour through `cn()`:
  `attention-chip.tsx`, `lock-pill.tsx`, `app-icon.tsx`, `menu.tsx`, and any page class.
- `tracking-label` and `tracking-brand` are custom letter-spacing values with the same risk next to a `tracking-*`
  utility.

## Change

1. `cn()` uses `extendTailwindMerge`, which tells it about the theme's custom font sizes (`label`, `micro`) and custom
   tracking (`label`, `brand`). Read the theme from one list kept next to the CSS variables, or name them once in
   `utils.ts` with a comment that points at `globals.css`. Keep the same signature.
2. A vitest test on `cn()` covers these cases:
   - `cn("text-label", "text-ink-2")` keeps both;
   - `cn("text-label", "text-sm")` keeps only the last size;
   - the same for `text-micro` and for `tracking-label` next to `tracking-wide`.
3. A test on `Badge` covers each tone: the rendered class list has `text-label`.
4. Look at a page with badges at 1280 and 390 px in both themes, for example Agents, Skills or Memory. Note in the
   report anything that now looks too small or misaligned. The intended size is the design system's (`docs/14`
   §Visual design), so fix layout around it only if something breaks.

## Tests move with the UI

Grep `web/tests` and `web/e2e` for assertions on badge classes or computed font size, and update them. Never loosen an
assertion.

## Placement

One Sonnet lane, size S, web only (`web/src/lib/utils.ts`, tests). It touches a shared helper, so run the vitest files
of the primitives that use `text-label` or `text-micro` plus the four drift guards. Normal code review by the
Orchestrator. Tests only through `scripts/dev/test.sh`.
