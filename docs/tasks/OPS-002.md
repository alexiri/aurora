# OPS-002: CI pipeline stages 1–2 + architecture guard scripts

## Goal
GitHub Actions workflow implementing `18 §CI pipeline` stages 1–2 and the architecture guards available in M0.

## Linked requirements
- M0/18§CI; `18 §CI pipeline` (1: fmt, clippy -D warnings, cargo deny, pnpm lint + type-check; 2: unit + database + service + contract tests), `18 §Architecture guards`, SEC-33.

## Context
- Repo layout `02`; Rust workspace root `Cargo.toml`; dashboard `web/` (pnpm 10, Node: use 22 in CI — local dev uses 20, both must work); DB tests need Postgres 16 and `DATABASE_URL` (sqlx macros compile online, I-05): CI service container `postgres:16`, then `sqlx migrate run --source crates/aurora-db/migrations` (install `sqlx-cli` 0.8.6 with `--no-default-features --features postgres,rustls --locked`, cache it).
- Schema guard: `python3 scripts/extract-schema.py --check` and `cargo test -p aurora-db --test schema_matches_spec` (TEST-001).
- Dashboard contract: `pnpm gen:api` must not change `web/src/lib/api/schema.d.ts` (`git diff --exit-code`).

## Scope
### In scope
- `.github/workflows/ci.yml`: jobs `rust-lint` (fmt, clippy `--workspace --all-targets --all-features -D warnings`), `rust-deny` (`EmbarkStudios/cargo-deny-action`), `rust-test` (postgres service; migrate; `cargo test --workspace`), `web` (pnpm install frozen, lint, typecheck, test, build, gen:api drift), `guards` (scripts below). Cache cargo registry/target and pnpm store.
- `deny.toml`: licenses allow-list typical for Apache-2.0 project (MIT, Apache-2.0, Apache-2.0 WITH LLVM-exception, BSD-2/3-Clause, ISC, Unicode-3.0, Zlib, MPL-2.0, CDLA-Permissive-2.0, OpenSSL if aws-lc requires), advisories deny, sources crates.io only.
- `scripts/guards/no-integration-names.sh` (SEC-33): case-insensitive grep over `crates/` and `services/` (not `connectors/`, `plugins/`, `docs/`, `tests/`) for chat-platform and app names: `mattermost slack discord telegram msteams github gitlab bitbucket jira confluence gmail notion linear sentry salesforce hubspot zendesk`. Allow-list file `scripts/guards/integration-names.allow` (path:regex lines) for justified exceptions (e.g. `known_llm_hosts`, which are LLM provider hosts and allowed). Exit non-zero listing offending lines.
- `scripts/guards/dep-graph.sh`: `cargo tree -p aurora-api -e normal -i wasmtime` and same for `aurora-gateway` must find nothing; `cargo tree -p aurora-policy -i aurora-db` must find nothing.
- `scripts/guards/run-all.sh` invoking all guards + schema check.

### Out of scope
- Image builds, e2e, nightly (later OPS tasks).

## Acceptance criteria
- [ ] `bash scripts/guards/run-all.sh` passes locally (report output).
- [ ] Workflow YAML is valid (`python3 -c 'import yaml…'` or `actionlint` if available); every command it runs was executed locally at least once and passed (report which; cargo-deny may be skipped locally if not installed — say so).
