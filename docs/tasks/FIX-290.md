# FIX-290: a self-hosted app's host is an allowed private host automatically (owner, 2026-11-28, D-511, security)

## Why

FIX-200 (D-437) made internal-only hosts reachable by listing them once in Helm (`privateHosts.names`). Its brief left
"an implicit allowance for hosts an instance admin registers as self-hosted apps (no Helm edit per host)" as a
follow-up with its own decision. The owner decided on 2026-11-28: "yes, add it automatically" (D-511).

## Decision (D-511)

A host that an **instance administrator** registers as a self-hosted app is reachable **by that app's requests** even
when it resolves to a private address, without a Helm edit.
- **Who:** only apps an instance administrator registers or approves at the instance level. An organization-level
  custom app gets nothing.
- **What:** only that app's own requests, through the gateway's matched app. Only the registered host name, with the
  same normalisation and rules as `privateHosts.names` (lower case, at least two labels; no addresses, no CIDRs). Only
  the app's declared ports, or the `privateHosts.ports` default.
- **Never:** loopback, link-local, cloud metadata addresses, or Aurora's own service addresses. The gateway's
  existing refusal of those stays first.
- The Helm list keeps working, and is still what any other traffic needs.

## Change

1. Read `docs/tasks/FIX-200.md`, D-437, the gateway's private-address check (`allowed_private`), and how a self-hosted
   app's host is stored (the instance app registry, `instance` placeholders).
2. Give the gateway's check a second source of allowed names, the self-hosted apps' hosts. Keep the result per app:
   one app's registration must not open its host to another app, or to an agent's other requests. A name removed from
   the app, or the app removed or disabled, stops being allowed at once. Use the existing config refresh, not a restart.
3. Administration shows these hosts as allowed because of the app, next to the Helm list, read-only.
4. Update `docs/04` or `docs/09` (where D-437 is described), `docs/17` with a SEC row, and the operator docs.

## Tests (each must fail before the fix)

- A self-hosted app whose host resolves to a private address: its own tool call reaches it, with no Helm entry.
- Another app's request to the same host is refused, and so is the agent's open-lane request.
- An organization-level custom app on a private host is refused.
- A registered name that resolves to loopback, link-local or a metadata address is refused.
- Removing or disabling the app removes the allowance.
