## Problem (code review of `09e955c9..bc7857ad`, web/)
1. **Real-stack Playwright specs race under `fullyParallel`.** `web/playwright.config.ts` (VEL-001) runs 4 workers fully parallel; `first-run`, `m1`, `no-default-model`, `onboarding-journeys` share one kind stack (instance, placement, users) and can corrupt each other; `retries` is left at Playwright's default (can mask flakes). Mocked visual specs (`fix-027-shots`, `onboarding`) write screenshots to fixed `/tmp/aurora-screens/...` paths (shared mutable state) and use `waitForTimeout(300)`.
2. **Groups list silently truncated at 200** (`web/src/lib/api/groups.ts` `useGroups` ~48 and `useGroupWorkspaces` ~84 request `limit: 200` and never follow `next_cursor`); C-460 allows 500 groups per org — groups past 200 vanish from the groups page and the group-access picker.
3. **Terminal: abnormal close never auto-retries** (`web/src/components/agents/terminal-tab.tsx` ~167–193: close 1006 / handshake failure → "ended" immediately, contrary to the file's own comment that reconnects back off).
4. **Getting-started Dismiss can wipe other dismissals** (`web/src/components/onboarding/getting-started.tsx` ~135–141): sends `[...(onboarding.data?.guide_dismissed ?? []), wsId]` — `PatchOnboarding.guide_dismissed` replaces the whole list; with the GET pending/failed (`retry: false`) it replaces it with one entry. The unit test (`web/tests/onboarding.test.tsx` ~187) starts from `[]`.
5. **Tour hijacks keys** (`web/src/components/onboarding/tour.tsx` ~108–125): window-level keydown `preventDefault`s ArrowLeft/Right with no target check (caret can't move in any input while the tour is open); Escape records `tour_completed: true` (never re-offered); the "Enter or →" comment is wrong (Enter does nothing on the card).
6. **Setup wizard step 3 stays stale after adding the LLM key** (`web/src/components/admin/setup-view.tsx` ~226: `LlmKeyForm` without `onSaved` → `["admin","setup"]` not invalidated).
7. **Connector approval checkbox survives a digest change** (`web/src/components/connectors/approval-panel.tsx` ~12–31: `reviewed` state isn't reset when `c.manifest_digest` changes on refetch → the user approves content they didn't tick for). Key the panel on the digest.
8. **Grant editor allows saving an empty custom grant on a custom-only app** (`web/src/components/agents/grant-editor.tsx` ~138–190; the server answers 422 `empty_custom` as a generic error). Disable Save when nothing is allowed/asked (as `GiveAccessPanel`'s `needsTools` does).
9. **Getting-started "Not now" is a no-op** (`getting-started.tsx` ~226 `onDismiss={() => undefined}`) and the waiting-state hello `<Link>` is only `aria-disabled` (still focusable/navigable).
10. **`useAgentReplied` polls every 10 s forever with N+1 requests** (`web/src/lib/onboarding/use-guide.ts` ~13–33) for workspaces whose agent never answers — add a backoff/cap.
