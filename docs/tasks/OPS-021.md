# OPS-021: Dependabot (phase 4)

## Goal
Automated dependency update PRs for every ecosystem in the repository, grouped to keep the PR volume manageable and the CI cost low.

## Scope
- `.github/dependabot.yml` with:
  - `cargo` (root workspace)
  - `npm` (pnpm, `web/`)
  - `github-actions` (SHA-pinned actions from OPS-019/020)
  - `docker` (base images in `images/**`; the pinned digests in `deploy/**` and scripts that Dependabot can parse)
- A weekly schedule and **groups**: patch+minor per ecosystem grouped; majors separate; security updates immediate. Add ignore rules for deliberately pinned items, each with a reason:
  - the wasmtime line (I-…)
  - VidaiMock/LiteLLM digests (I-30)
  - Mattermost 11.7 (MM-003)
  - the claude-code CLI pin
- `open-pull-requests-limit` per ecosystem.
- Labels.
- Document the review policy for dependency PRs in `docs/ops/dependencies.md`: what CI must pass, how `cargo deny` gates them, and who merges.

## Acceptance criteria
- [ ] Valid `dependabot.yml` (GitHub's schema).
- [ ] The first Dependabot run produces grouped PRs as configured (verified by the coordinator after push).

## Phase
Phase 4 (owner, 2026-11-08).

## Suggested agent/model
Haiku (config + doc), Sonnet if the ignore list needs investigation.
