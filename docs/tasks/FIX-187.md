# FIX-187: The collapsed status strip's divider lines up with the thread header

## Goal
Owner, 2026-11-20 (D-403). On the agent's Chat page with the status rail **collapsed** (the 56 px strip), the
divider under the strip's expand button (‹) sits a few pixels above the thread header's bottom border, so the two
horizontal lines do not meet. With the rail **expanded** they form one line: the "Status" header and the thread
header are both 64 px (P5-POLISH-6). Make the collapsed strip line up the same way. The owner allows the divider
to run the strip's full width, and that is the fix chosen here.

## Cause
`web/src/components/agents/status-rail/status-rail.tsx`, the collapsed `strip` (about line 197): the aside is
`flex w-14 flex-col items-center gap-1 … py-2`; the expand button is `size-10`, then
`<hr className="my-1 w-8 border-0 border-t border-line" />`. The divider lands at about 8 + 40 + 4 = 52 px, while
the thread header (`web/src/components/chat/thread-header.tsx`, `md:h-16 border-b`) ends at 64 px.

## Change
1. The strip's top is a 64 px cell the full width of the strip (`h-16 w-full shrink-0`, `border-b border-line`,
   content centred) holding the expand button, the same height and border as the expanded panel's
   `<header className="flex h-16 … border-b border-line">`. Its bottom border is the divider; remove the `<hr>`.
2. The five part icons follow below with the spacing they have today (the `gap-1` column, top padding equal to
   today's gap under the divider). Their order, labels, tooltips, dots, the Needs you count and pop-over, focus
   return after collapse and Esc in overlay mode are unchanged.
3. The strip's `border-l` and the cell's `border-b` meet without a gap or a double line. Overlay mode (chat panel
   under 1024 px: strip under the expanded panel) still looks as today.
4. Tokens only, both themes (14 §Visual design). The strip exists from 768 px up; below that the Status sheet is
   unchanged.
5. Docs: in `docs/14-web-dashboard.md` §Agent page, "**Rail states.** … Collapsed: a 56 px strip with an expand
   button ("Expand status panel") and the five icons", add: (phase 5, FIX-187, D-403) the expand button sits in a
   64 px top cell whose bottom border runs the strip's width and continues the thread header's bottom border, as
   the expanded panel's header does.
