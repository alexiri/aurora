# CLI-001: `aurora-client` + `aurora` CLI — login (device flow), run (BYO), approvals watch

## Linked requirements
- M2 `19 §M2` ("CLI `login`, `run`, `approvals watch`"), `04 §CLI login (device flow)`, `08 §10 BYO bootstrap` (`aurora run -- <cmd>`: writes CA to a temp file, sets env, builds a combined CA bundle), `16 §W12` (CLI); `02` (`aurora-client` typed HTTP client used by CLI and tests; config dir `~/.config/aurora`).

## Context
- Read `docs/16-wire-protocols.md §W12` and `docs/08-secrets-credentials.md §10`. Contract rows: `/v1/auth/cli*`, `/v1/agents/{agent}/container-config`, `/v1/agent/container-config`, `/v1/approvals/pending`, `/v1/approvals/{id}/decision`, `/v1/resolve`, `/v1/me`.
- `aurora-client`: hand-written typed client over `reqwest` with serde types mirroring the contract (generating from OpenAPI is optional; keep types in `aurora-client`, not in `aurora-protocol`).

## Scope (`crates/aurora-client/**`, `services/aurora-cli/**`)
- `aurora login [--url <external_url>] [--hostname]`: device flow, prints user code + verification URL, polls respecting `interval`/`slow_down`, stores `{url, api_key, workspace}` in `~/.config/aurora/config.toml` (0600).
- `aurora agents list`, `aurora agents token <handle>` (regenerate; prints token once; stores it under the agent's entry, 0600).
- `aurora run --agent <handle> -- <cmd…>`: fetch container config (agent token if stored, else API key + placeholder substitution), write CA to a temp file, build combined bundle (system roots + gateway CA), exec child with env; exit code passthrough.
- `aurora approvals watch [--workspace]`: long-poll `/v1/approvals/pending`, print summaries, interactive `a`/`d`/`s` (skip) decisions (non-interactive `--json` mode streams JSON lines).
