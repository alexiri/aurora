# GW-010: Gateway — registry snapshot loading, app-connection candidates, app/tool identification, mechanisms

## Goal
The gateway serves **app connections** declared by plugin packages: loads the active snapshot, finds app candidates, identifies app/tool per request, and executes the manifest mechanisms (inject, route, guard, finalize, transform, intercept, passthrough) for static-token connections. OAuth refresh and `token.mint` are GW-011.

## Linked requirements
- M3/06 `§Registry snapshot loading` (highest supported contract; refuse unknown mechanisms keeping the previous snapshot; ArcSwap; readyz until loaded; `aurora_registry` NOTIFY + 30 s poll of the active hash), `§MITM lane: connect-time resolution` steps 2 (app candidates via host index; tenant-bound `tenant_host` match) and 6 (app availability: `org_app_availability` when org posture `restricted`, remember for `app_unavailable`), `§Per-request pipeline` steps 5 (app and tool identification incl. GraphQL kind and git op via aurora-policy classifiers), 6 (selection precedence: app connection over generic secret; ambiguity `multiple_connections`; `x-aurora-connection-id`; `x-aurora-connections` response header), 9 (`intercept: oauth_token_endpoint` synthetic token response), 11 (mechanisms), 12 (finalize `aws_sigv4`, transform `git_commit_trailer`), 14 (guidance: `host_mismatch` 421, `app_not_connected`, `app_path_unserved`, `access_restricted` with `details.reason=disabled`; `registry_token_challenge` passthrough); `09 §4 Template substitution` (escaping by destination; empty optional values abort `bearer`/`basic` with `credential_unavailable`), `§5 Mechanisms`; SEC-04, SEC-05, SEC-16, SEC-17 (rewrite_host/tenant constrained to zone at runtime too), SEC-37 (no app connection on governed LLM hosts).
