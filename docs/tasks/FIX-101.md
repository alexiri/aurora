# FIX-101: CI runs what the documents say it runs, and a skipped suite is a failure (REVIEW-5 WEBA-2, OPS-2/3, CNT-5, SEC-2, PLUG-10, AUTH-7, DB-10, DEP-4/7/10/11) — **high**

## Problem
Several suites that the specifications cite as evidence never run in CI, and they pass when skipped:
1. **Playwright.** No workflow runs the dashboard Playwright specs except `first-run.spec.ts` in the nightly (`.github/workflows/ci.yml` web job ~242–260; `nightly.yml` ~50). `docs/18` ~18: "Playwright flows … every PR". The terminal CSP spec reads the `next dev` header, so it cannot see the production policy.
2. **Gateway front doors.** `ci.yml` ~188 runs `scripts/e2e/gateway.sh` without `FRONTDOOR=1`; `tests/e2e-gateway/tests/frontdoor.rs` prints `SKIPPED` and passes. `docs/18` ~16: "CI-only strict front doors" (TEST-021, born from the FIX-052 production incident).
3. **Podman sandbox hardening.** `services/aurora-runner/tests/it/podman.rs` returns early unless `AURORA_TEST_PODMAN` is set; the only job that sets it runs other binaries (`scripts/e2e/hosted.sh` ~92). SEC-26's live assertions never run.
4. **Redis counters.** `crates/aurora-counters/tests/it/conformance.rs` (~658–694) skips without `AURORA_TEST_REDIS`; no workflow sets it; `docs/18` ~422 says CI starts Redis. SEC-62's backend-equivalence claim excludes one backend.
5. **Channel e2e.** `scripts/e2e/channels.sh` is in no workflow; SEC-18/19/20 cite it. The SEC-41 browser path (`hosted.rs` s8d) needs an image CI never builds.
6. **Tests that cannot fail.** The permission matrix records a 400/422 on a denial row as INCONCLUSIVE and passes (`services/aurora-api/tests/it/permission_matrix.rs` ~1269–1282). The schema guard compares table and column names only (`crates/aurora-db/tests/it/schema_matches_spec.rs` ~80–125). Fourteen manifest rule codes have no invalid fixture (`plugins/fixtures/expected-invalid.txt`: `hooks_wasm_import_forbidden`, `hooks_wasm_export_unexpected`, `hooks_wasm_not_component`, `hooks_wasm_invalid`, `unknown_context`, `unknown_oauth_client`, `bad_tenant_field`, `bad_version`, `archive_corrupt`, `archive_entry_type`, `guide_not_utf8`, `manifest_not_utf8`, `tool_path_invalid`, `undeclared_field`).
7. **Guards.** `no-live-tokens.sh` scans only `plugins/builtin`; `no-dev-idp-in-release.sh` checks one Containerfile; `dep-graph.sh` treats "did not match any packages" as a pass.
8. **Cache and claims.** The sandbox-image cache key omits manifests, toolchain files and `scripts/images/**` (`ci.yml` ~216). `docs/18` ~915 claims multi-arch images on main (CI builds amd64 only) and ~918 a nightly performance run (there is none).
