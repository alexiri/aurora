# FIX-086: The gateway upgrades only WebSocket; refused CONNECT authentications are logged at a bounded rate (REVIEW-5 CNT-3, CNT-8) — **medium, security**

## Problem
1. **Any `Upgrade` token becomes a byte pipe.** `services/aurora-gateway/src/hygiene.rs` `requested_upgrade` (~47–52) returns whatever `Upgrade` value the request carries when `Connection` names `upgrade`; `proxy/mod.rs` (~267–271) does not compare it with `websocket`; `upstream.rs` (~320–326) forwards it on HTTP/1.1; any `101` turns the connection into a raw `bridge` (`proxy/mod.rs` ~407–421). `docs/06` ~554–556 specifies WebSocket only: "steps 1–11 run on the upgrade request; then the connection becomes a byte pipe". After the 101 nothing passes the pipeline: no method/path rules, no injection decisions, no per-request log. An agent whose rule allows `GET /public` can send `Upgrade: h2c` to a plain-HTTP upstream that accepts it and then speak HTTP/2 to every path.
2. **Unbounded warn logging.** `proxy/mod.rs` `connect_refused` (~459–467) writes a `warn` line for every refused CONNECT authentication (missing, unknown, revoked, expired credential; called from `authenticate` ~217–245). The BYO gate beside it uses `self.refusals.should_log` (~145–168). An unauthenticated flood writes one line per request.

## Linked requirements
- `docs/06` §WebSocket upgrades; `docs/17` gateway invariants (every request passes the pipeline); C-630 / D-165 (CONNECT-auth refusals observable).

## Scope
### In scope
- `requested_upgrade` accepts only `websocket` (ASCII case-insensitive, single token). For any other token: strip `Upgrade` and the `upgrade` connection option and forward a plain request.
- A `101` from upstream when the gateway did not forward an upgrade is a protocol error: 502 to the agent, connection to that upstream closed, logged once.
- `connect_refused`: count every refusal in the metric; log through the existing `RefusalLimiter` keyed by source address (or `unknown`), at most once per interval.
- `docs/06`: one sentence that other upgrade tokens are forwarded as plain requests.

### Out of scope
- Header-set oracles (TEST-021 covers them).
