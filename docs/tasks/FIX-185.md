# FIX-185: Suspending someone in an organization also stops their running turns

## Goal
Owner, 2026-11-19 (D-401). P5-APIGAP-4 found that `PATCH /v1/orgs/{org}/members/{user}` with
`status: suspended` (a person suspends a member organization-wide) does not end the member's queued or
running turns, while SCIM deprovisioning and the new workspace suspension (P5-APIGAP-4) do. A suspended
person's agent should not keep acting for them. The org suspension ends their turns too.

## Change
1. In the org member PATCH, when the status goes to `suspended`, end the person's queued and live
   **speaker turns in every workspace of that organization**, in the same transaction as the status change.
   Use `abort_speaker_turns(&mut tx, org, None, user, &END)` (the helper SCIM and P5-APIGAP-4 share,
   `services/aurora-api/src/domains/scim/deprovision.rs`). End code `user_suspended`, notice "This turn was
   stopped: the person was suspended in this organization." Flush the deltas after commit as P5-APIGAP-4's
   `set_access_status` does. Restoring (`active`) starts nothing.
2. Nothing else about the org PATCH changes. If other paths suspend an org member (an admin bulk action, an
   instance-admin user suspension across orgs), list them in the Completion report and say whether they
   already end turns. Make each one that doesn't end them call the same helper. Do not change SCIM.
3. Docs: `04` (what an organization suspension ends), `API_CONTRACTS` where the org member PATCH is
   described.

## Tests
API IT: a member with a queued turn and a running turn in two workspaces of the org is suspended. Both
turns end `aborted`/`user_suspended` with the notice, and a turn of another member is untouched. Restore
leaves the ended turns ended. The existing org-member and SCIM ITs stay green. Targeted only (CI is the
gate). Also run `cargo fmt --check` and clippy on aurora-api.

## Ownership
The org members domain in `services/aurora-api` (and any other suspension path found in step 2). Size S.
D-401.

End code `user_suspended`, the specified notice. Restoring starts nothing. SCIM is unchanged.
