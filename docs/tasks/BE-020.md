# BE-020: `aurora-policy` — matchers, GraphQL/git classification, rule model, injection selection, evaluator

## Goal
The single implementation of policy matching and evaluation (D-02), pure and I/O-free, used by the gateway and the API.

## Linked requirements
- M2/07: `07 §One rule model…`, `§Rule sources and order`, `§Rule anatomy`, `§Matching primitives`, `§Injection selection`, `§Evaluation`; D-08, D-09, D-10, D-11; SEC-03 (selection before decision, ids only), SEC-08 (doubt tightens), SEC-38/39 (uncredentialed default; scopes only tighten); `18 §Policy and gateway` (matcher property tests, evaluator corpus).

## Context
- Read `docs/07-policy-approvals.md` from the top through `§Evaluation` (ends before "## Grants and their compilation"). That text is normative; implement it exactly.
- Rule storage shapes: `docs/03-data-model.md` `policy_rules` and `derived_rules` (§4) — the rule JSON you deserialize must match those columns/jsonb shapes (read only those two tables).
- `aurora-policy` MUST NOT depend on `aurora-db` or do I/O (`02`, guard in `scripts/guards/dep-graph.sh`). Workspace deps available: `serde`, `serde_json`, `serde_yaml`, `uuid`, `graphql-parser`, `thiserror`, `proptest`, `aurora-core`. Do not edit root `Cargo.toml`.

## Scope
### In scope (`crates/aurora-policy/**`)
- `host`: `HostPattern::parse` (lowercase, no trailing dot, exact or exactly one `*`, optional `:port`; >1 `*` → error) and `matches(host, port)` (runtime-invalid pattern matches nothing).
- `path`: `PathPattern::parse/matches` (literal, `*` one non-empty segment, trailing `**`, segment-prefix `lit*`; query never participates). Paths given to matchers are already normalized (gateway refuses ambiguous paths, D-11) — still never panic on any input.
- `methods`, `graphql::classify(body_prefix, truncated) -> GraphqlKind {Query, Mutation}` (batch arrays, operationName selection; any doubt ⇒ Mutation), `git::classify(path, query) -> Option<GitOp {Push, Fetch}>`.
- `rule`: `Rule { logical_id/name (for trace), identities, targets, action, require_approval, rate_limit, conditions, enabled }` with serde matching `03`/`07`; `Target` enum (app, connection, app_connections, secret, secrets, network); `Condition` with truncation/unparsable ⇒ Unknown resolved by rule polarity.
- `facts`: `RequestFacts` per `07 §Rule anatomy` (host, port, path, method, body_prefix + truncated, app_id, tool_id, tool tags needed for graphql/git (pass the tool's classification inputs as facts), winning_credential, injected, is_llm_host, identity {agent_id, principals}).
- `select::selected_candidates(rules_of_both_scopes, identity, candidates) -> set` per `§Injection selection`.
- `eval`: `ScopePolicy { ordered_rules, default_action, uncredentialed_default, uncredentialed_allowlist }`; `evaluate(org, ws, facts, counters: &dyn RateCounter) -> Decision { verdict: Allow | NeedsApproval | RateLimited | Block{reason: Rule|DefaultDenied|EgressDenied}, matched rules per scope, trace }`; strictness `block > rate_limited > needs_approval > allow`; `RateCounter` trait (`is_exhausted(rule_key, agent, window) -> bool`, `record(...)`) — increments only when the final verdict is allow/needs_approval (expose `Decision::rate_limit_hits()` for the caller to record). In-memory `MemoryCounter` impl (D-05) for tests and the gateway.
- Trace type serializable (used by simulate and request log).
- Tests: `proptest` for host/path matchers (never panic; documented examples); GraphQL table tests (query, mutation, subscription, batch mixed, operationName, truncated, invalid JSON, missing query ⇒ mutation); git classification; **evaluator corpus** `crates/aurora-policy/tests/corpus/*.yaml` (each file: facts + org/ws scope policies + expected verdict/reason/matched rule) with ≥20 cases covering: scope combination both directions, workspace allow cannot loosen org block, hand before derived order (D-09), default carve-out for LLM hosts, default_denied vs egress_denied reporting, uncredentialed default with allow-list and explicit allow rule override, rate-limit exhausted vs not and no consumption when blocked, condition polarity with truncated body, GraphQL fail-closed, git push block, injection selection (connection id, app_connections scope coverage, secrets kind, `app`/`network` never select, no selecting rule ⇒ empty).

### Out of scope
- Grant compilation into derived rules, authoring/warnings/simulate API (later M2 tasks), gateway wiring.
