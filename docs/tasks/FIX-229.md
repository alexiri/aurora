# FIX-229: trim the built-in Grafana app to three skills; `sweep` leaves the built-in (owner 2026-11-22)

## Why

Owner, 2026-11-22: "I'm worried about the grafana app becoming so large. can it be trimmed down?", then "ok,
drop sweep. write up the whole thing". Decision **D-471**.

After FIX-227, `plugins/builtin/grafana` (grafana 1.4.0) ships five skills and three scripts:

| Skill | SKILL.md | Script |
|---|---|---|
| `grafana-query` | 8,891 | `grafana-query` 21,777 |
| `grafana-api-notes` | 8,516 | — |
| `grafana-opensearch` | 8,677 | `grafana-os` 10,552 |
| `grafana-prometheus` | 3,628 | `grafana-prom` 22,928 |
| `grafana-investigate-a-spike` | 4,301 | — |

That is 89,000 characters: twice Indico (43k) and more than ten times any other built-in app (2–7k).

- **Context cost:** two descriptions say "read before the first request/query" (`grafana-api-notes` and
  `grafana-query`), so a typical Grafana task reads about 17,000 characters before acting.
- **Overlap:**
  - `grafana-api-notes` and `grafana-query` both cover data source UIDs, querying and errors.
  - `grafana-investigate-a-spike` step 4 ("compare with the day before") is what `grafana-prom compare` does.
  - `grafana-opensearch` still teaches writing the query body by hand at length, although `grafana-os` builds it.
- **Maintenance:** about 1,300 lines of Python in three scripts, each with a copy of the same helpers
  (FIX-227's drift check pins them). The largest piece, `sweep` (node health and filesystem days-to-full with
  default checks, a `--checks` file and placeholders), is a site's operations recipe from the NightManager
  agent's review, not general Grafana know-how.

## Decision

**D-471** (in `docs/90-decisions.md`):
- Three skills: `grafana-query`, `grafana-prometheus` and `grafana-opensearch`. `grafana-api-notes` and
  `grafana-investigate-a-spike` go.
- `sweep` leaves the package. An organization that wants it keeps it as its own skill, which outranks app
  skills anyway (D-453(c)).
- Budgets, checked by the app's stubbed test:
  - all skill files (SKILL.md bodies and scripts) together ≤ **59,000** characters (first written as 50,000;
    raised by the Orchestrator during the lane, because the three scripts that remain are 42,878 after `sweep`);
  - SKILL.md bodies together ≤ **16,000**;
  - only `grafana-query`'s description says to read it first.

No other numbers: no contract, SEC, or migration. grafana becomes **1.5.0**.
