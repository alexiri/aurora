# GW-002: Gateway DB credential resolver, instance registration, NOTIFY cache invalidation

## Goal
Real credential authentication for the proxy (replacing `DenyAllResolver`), gateway instance bookkeeping, and the invalidation plumbing every later gateway cache uses.

## Linked requirements
- M2/06 `§Credential authentication` (lookup by SHA-256 hash in `gateway_credentials`; rejected when revoked, expired, agent/workspace/org gone, or org without an active owner; context credentials valid until `expires_at`; identity incl. `principals = {agent} ∪ users with can_use on the workspace`), `§Caches and invalidation` (credential cache 60 s; scopes `credential`, `agent`, `workspace`, `org`, `all`, plus `aurora_auth_revoked`; on LISTEN loss flush all caches except leaf certs), `§Statefulness and replicas`; `03 §gateway_instances` (row per process start, `last_seen_at` every 15 s, `stopped_at` on shutdown), `03 §Gateway database role grants` (gateway uses only the granted reads/writes); `05 §Event bus` (`aurora_gateway_invalidate`, `aurora_auth_revoked`); SEC-10, SEC-21 (suspended members are not principals), SEC-25 (context credential expiry).

## Context
- GW-001 code: `services/aurora-gateway/src/auth.rs` (`CredentialResolver`, `RequestIdentity`, `DenyAllResolver`), `main.rs` (`serve`), `lib.rs`.
- `aurora-db`: `bus::{Listener, BusEvent, Channel}`, `authz` (access law). Tables: `gateway_credentials`, `agents`, `workspaces`, `organizations`, `org_members`, `workspace_access` (`03 §1`, `§5`). Access law: `04 §The access law`.
- The gateway's DB role may lack write privileges on most tables: only write `gateway_instances` (and later approvals/request_log/app_connections columns).

## Scope
### In scope (`services/aurora-gateway/src/{resolver.rs,instance.rs,invalidation.rs}`, wiring in `main.rs`, `crates/aurora-db/src/repo/gateway.rs` (+ `repo/mod.rs` export line only))
- `repo::gateway`: `find_credential_identity(pool, token_hash) -> Option<CredentialIdentityRow>` — one query joining credential → agent → workspace → org, filtering `revoked_at IS NULL`, `expires_at IS NULL OR expires_at > now()`, and requiring the org to have ≥1 active owner; `principals(pool, workspace_id) -> Vec<Uuid>` (active org members who are owner/admin, or have `workspace_access`); `register_instance`, `heartbeat_instance`, `stop_instance`.
- `DbCredentialResolver`: hash token (`aurora_core::token::hash`), reject non-`aug_/aub_/auc_` prefixes without a DB call, cache identity (incl. principals) 60 s keyed by hash; negative results not cached longer than 5 s.
- `Invalidation` hub: one LISTEN connection (`aurora_db::bus::Listener`) on `aurora_gateway_invalidate` + `aurora_auth_revoked`; dispatches typed events (`Scope::{Org(id), Workspace(id), Agent(id), Credential(id), Connection(id), All}`) to registered caches via a small trait (`fn invalidate(&self, ev: &Invalidate)`, `fn flush_all(&self)`); on `BusEvent::Resync` → `flush_all` on every cache. Credential cache keeps reverse indexes (org/workspace/agent/credential id → hashes) to drop precisely.
- Instance: insert `gateway_instances` row at startup (hostname, version), heartbeat every 15 s, `stopped_at` on graceful shutdown; `/readyz` (4103) requires DB reachable **and** listener connected.
- `serve` uses `DbCredentialResolver` (keep `DenyAllResolver` for tests).

### Out of scope
- ResolvedHost/policy/injection (GW-003+); issuing credentials (API M2 BYO task).

- [ ] End-to-end through the proxy (reuse GW-001 test helpers): a request with a valid `aug_` token is forwarded; revoked → 407.
- [ ] Instance row registered and heartbeat updates `last_seen_at`.
