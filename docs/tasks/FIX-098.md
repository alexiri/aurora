# FIX-098: Terminal tab — colours that render, close codes handled as specified, no reconnect storms (REVIEW-5 WEBA-1/3/4/5/13/14/17/18/19, EVID-6) — **high**

## Problem
1. **Every ANSI colour is invalid in both themes** (coordinator-verified). `web/src/app/globals.css` (~223–242) defines `--term-color-N: var(--term-color-N)` on `.wterm.term-pane` — a custom property that references itself is a cycle and computes to invalid, masking the `:root` palette (~183–220). The comment calls the palette "contrast-checked"; nothing is shown.
2. **In production the terminal has no colours or wide-cell spacing at all** (code path verified; not observed in a browser). wterm's DOM renderer builds row HTML with `style="…"` attributes (`@wterm/dom` `dist/renderer.js` ~155–170, inserted via `innerHTML`). The production CSP is `style-src 'self' 'nonce-…'` (`web/src/proxy.ts` ~23); a nonce does not cover style attributes, so the browser drops them. Development adds `'unsafe-inline'`, and Playwright runs `next dev`, so no test sees it. C-622 says the CSP gains `'wasm-unsafe-eval'` and "nothing else loosens"; `docs/14` §Terminal promises DOM rendering with 24-bit colour. Both could not hold. **Decided by the owner on 2026-11-13 (Q-R5-2, D-176): the policy gains exactly `style-src-attr 'unsafe-inline'`** — inline style *attributes* only; `<style>` elements and stylesheets stay bound to `'self'` and the nonce. C-622 and `docs/14` §Security headers already say so; this brief changes `web/src/proxy.ts` to match.
   **Observed by the owner 2026-11-13, worse than stated:** the style attribute also carries each run's cell span (`--term-span-cols`; `.term-row > span { width: calc(var(--term-span-cols, 1) * var(--term-cell-width, 1ch)) }`). With it stripped, every run is one cell wide and its text overflows: the cursor is drawn at about column 1 after the prompt, and any line with more than one styled run (`top`'s header) overlaps itself. **The directive landed as a coordinator hotfix on 2026-11-13** (`web/src/proxy.ts`, both policies). The lane still owns the production-build test that proves it, and everything else in this brief.
3. **Final close codes are retried while waking.** `web/src/components/agents/terminal-tab.tsx` (~177–182) reconnects on any close when the sandbox is `starting`, before the code is classified: 4403 (revoked), 4404 and 4409 never end the pane, and the loop has no cap — a sandbox stuck starting produces a handshake every 8 s, which can also spend the wake budget (12 per hour, C-621).
4. **4502/4503 are never retried.** The API sends them as real close frames, so `ev.wasClean` is true and the pane returns at the `wasClean` check (~184) before `RETRYABLE` (~190). The reconnect test uses `wasClean: false` everywhere.
5. Smaller: a frozen agent's pane says "paused" (~236); keystrokes typed while disconnected are dropped silently (~304); light-theme ANSI white is ~1.2:1 on the surface (`globals.css` ~189–198); `docs/14` and D-161 say the vendored WASM is ~400 KB and "hashed" — it is 599,368 bytes, named by version, with no recorded checksum (its sha256 matches the pinned `@wterm/ghostty@0.5.10`).
