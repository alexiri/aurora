# BE-012: Tenancy — organizations, workspaces, members, access bindings, default agent

## Goal
Org/workspace lifecycle including the creation transaction (default workspace, policy generations, Daneel), membership management and workspace access, plus read-only agents (C-05) and slug resolution.

## Linked requirements
- M1/04§signup (`04 §Sign-up and organization creation` steps 1–4), `04 §Roles`, `§Permission matrix`, `§Deletion semantics` (workspace, org), `10 §Default agent: Daneel`; `05 §Organizations, members, keys` (orgs, members), `§Workspaces` (CRUD, access), `GET /v1/resolve`; SEC-21, SEC-32. Contract: `docs/API_CONTRACTS.md` M1 rows for `/v1/orgs*` (not invitations/api-keys/audit), `/v1/workspaces/{ws}` (+ `/access`), `/v1/orgs/{org}/workspaces`, `/v1/resolve`, `/v1/workspaces/{ws}/agents`, `/v1/agents/{agent}`.

- Config: `hosted.default_timezone`, `hosted.enabled`, `hosted.default_harness`, `agents.default_name`, `agents.default_brief`, `auth.org_creation`.

## Scope
### In scope
- `crates/aurora-db/src/repo/{orgs,workspaces,members,agents,policy}.rs` (only functions needed here) and `services/aurora-api/src/domains/{tenancy,agents}/`.
- `tenancy::service::create_organization(tx, cfg, creator_user_id, name, slug: Option) -> CreatedOrg { org, workspace, default_agent }` — **public, used by sign-up (BE-011) and OIDC JIT (BE-015)**: one transaction: org (slug from name if absent: lowercase, non-`[a-z0-9]`→`-`, trim, collapse, ensure valid slug, suffix `-2`, `-3`… on collision only when slug was derived; explicit slug collision → 409 `slug_taken`; `external_id` = 32 random hex), creator `owner` active; then `create_workspace_in_tx` (below).
- `create_workspace_in_tx(tx, cfg, org_id, creator, name, slug, timezone, memory_language) -> (Workspace, Agent)`: workspace (`Default`/`default` for the first), creator `workspace_access` owner **only if** not org owner/admin? — No: `04` says creator is bound as `owner`; always insert the row. Policy generations for the **org scope (only when creating the org)** and the workspace scope: published `number=1` (no rules, default_action `none`, `published_at=now()`), draft `number=2`. Default agent per `10` (handle = slugified default name, `kind` hosted iff `hosted.enabled`, harness default, effort `medium`, `is_default=true`, brief from config, `created_by` creator).
- Validation: timezone via `chrono-tz`; memory_language must exist in `pg_ts_config` (`SELECT 1 FROM pg_ts_config WHERE cfgname=$1`) or be `simple`; names 1–80 chars (sanitize with `aurora_core::sanitize::one_line` for storage? — no: store trimmed input, reject control chars with 400).
- Routes per contract: orgs list/create/get/patch/delete (delete: owner, `confirm` slug; hand-written ordered delete of org children, ledgers remain — implement for tables existing now: workspaces (cascade), org-scoped rows with `restrict` FKs: delete explicitly in dependency order; enqueueing connector deprovisioning is out of scope until M6 — leave a `// M6:` note), members list/patch/delete (admins cannot touch owners or grant `owner`; last active owner cannot be demoted/suspended/removed → 409 `last_owner`; status `suspended` changes publish `aurora_auth_revoked {kind:"user", id}` so caches flush), workspaces list (owner/admin: all; member: those with bindings)/create (permission: owner/admin or `settings.members_can_create_workspaces` default true)/get/patch/delete (`can_own`; `confirm`), access list (includes implicit org owners/admins with `implicit: true`)/put/delete, `GET /v1/resolve`, agents list/get (read-only, `can_use`).
- `POST /v1/orgs` permission: `auth.org_creation` = `instance_admins` ⇒ caller must be instance admin, else 403 `org_creation_forbidden`; `anyone` ⇒ any signed-in user.
- Audit every state change (`org.create`, `org.update`, `org.delete`, `member.update`, `member.remove`, `workspace.create`, `workspace.update`, `workspace.delete`, `workspace_access.set`, `workspace_access.remove`).
- utoipa annotations + `web/openapi.json` regenerated + `pnpm gen:api`.

### Out of scope
- Invitations, API keys, audit routes, sign-up (BE-011/013/014/016). Agent create/update/delete (M2/M4).
