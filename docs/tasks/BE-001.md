## Scope
### In scope (`crates/aurora-core/**` only)
- `ids`: UUIDv7 generation (`new_id() -> Uuid`); validators for slug `[a-z0-9][a-z0-9-]{1,47}` and agent handle `[a-z][a-z0-9-]{0,39}`.
- `error`: `ApiError { status: u16 (or http::StatusCode), code, message, details: Option<serde_json::Value> }` serializing to `{"error":{"code","message","details"?}}`; code validated `≤64`, `[a-z0-9_]`; constructors for the status vocabulary (invalid_request with `details.fields=[{path,message}]`, unauthenticated 401, forbidden 403, not_found 404, conflict 409, too_large 413, unprocessable 422 with custom code, rate_limited 429 with retry-after secs, upstream 502/503/504). Feature `axum`: `impl IntoResponse` (JSON body, `retry-after` header for 429).
- `sanitize`: `one_line(s,max)`, `block(s,max)`, `label(s)`, `markdown_as_data(s,max)` exactly per `02 §Untrusted text` (strip C0/C1, bidi controls U+202A–202E, U+2066–2069, U+200E/F, U+061C, Unicode `Cf` incl. zero-width; whitespace collapse; trim; clamp by chars with `…`; `block` keeps `\n`, collapses >2 consecutive newlines). `markdown_as_data`: escape markdown/HTML-active characters so text renders literally; links shown with their target (document your approach).
- `limits`: every constant of `02 §Limits registry` as typed `pub const` (Durations as `std::time::Duration`, sizes in bytes as `usize`/`u64`, counts as `u32`), names exactly as in the table (compound rows → separate consts, e.g. `SKILL_NAME_MAX`, `SKILL_DESCRIPTION_MAX`; `SANDBOX_DEFAULTS` → `SANDBOX_DEFAULT_MEMORY_MIB` etc.). Module must have no dependencies.
- `token`: `TokenPrefix` enum for all 12 prefixes of `00`; `generate(prefix) -> Secret<String>` = prefix + base64url_nopad(32 bytes OS CSPRNG) (43 chars); `hash(token) -> [u8;32]` SHA-256; `display_prefix(token) -> String` (first 12 chars); `parse_prefix(&str) -> Option<TokenPrefix>`. Use `aws-lc-rs` (rand + digest).
- `secret`: `Secret<T: Zeroize>` wrapper: zeroize on drop, `Debug`/`Display` print `[redacted]`, **no** `Serialize`, explicit `expose(&self) -> &T`.
- `#![forbid(unsafe_code)]`.

### Out of scope
- Config, DB, crypto envelopes, HTTP servers, protocol types.

## Acceptance criteria
- [ ] Unit tests for each module; `proptest` property tests for sanitizers (never panic; output has no control/bidi/Cf chars; `one_line` output has no `\n`; length ≤ max chars) and slug/handle validators.
- [ ] Error envelope JSON snapshot/assert test (with and without details; invalid_request fields shape).
- [ ] Token tests: length 4+43, prefix round-trip, hash is 32 bytes and deterministic, two generations differ, `Debug` of Secret shows no value.
- [ ] `cargo test -p aurora-core --all-features` passes; `cargo clippy -p aurora-core --all-targets --all-features -- -D warnings` clean; `cargo fmt -p aurora-core --check` clean.
