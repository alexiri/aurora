# FIX-117: Dashboard lists follow their cursors; one-off styling replaced by tokens and primitives (REVIEW-5 WEBO-6/12, WEBC-2/8, WEBX-1/2/3/13) — **medium**

## Problem
1. **Lists stop at the first page without saying so.** The API pages at 50 by default and 200 at most (`services/aurora-api/src/http/pagination.rs`); these hooks never follow `next_cursor`:
   - `web/src/lib/api/queries.ts` `useWorkspaces` (a workspace past the 50th cannot be bound to a group);
   - `lib/api/account.ts` `useOrgMembers` (200, no search although `docs/14` says "add by name or e-mail"), `useAccess` (ignores `next_cursor` and `derived_cursor`), `useMyApiKeys`, `useWsKeys`;
   - `lib/api/org.ts` `useOrgInvitations`, `useOrgKeys`; `lib/api/apps.ts` `useConnections`;
   - `lib/api/freeze.ts` `useAdminOrgs` (the admin Organizations page and the placement default-org picker: an operator cannot freeze an org past the first page; when "Users" is not on page 1 the form offers to create it and then clashes on the slug);
   - `lib/api/approvals.ts` `fetchPending` (200) and `lib/api/action-approvals.ts` (100 — later action approvals cannot be decided from the dashboard);
   - `lib/api/agent-tokens.ts` `useOrgAttentionTokens` (newest 100 of stale/expiring tokens — the oldest, most stale ones are the ones dropped);
   - `lib/api/conversations.ts` `chatApi.list` (first 50 conversations; a deep link to an older one opens without title or kind);
   - `lib/api/governance.ts` blocked-host count (`workspaceIds.slice(0, 10)` and 100 rows each).
   `lib/api/groups.ts` `fetchAllPages` is the existing pattern.
2. **One-off styling against `docs/14` §Visual design** (tokens only; shared primitives; no arbitrary values): spacing offsets `sm:mt-[1.625rem]`/`ml-[1.625rem]` (`groups/group-detail.tsx` ~75, `settings/group-access.tsx` ~125, `automations/owner-controls.tsx` ~57); dialog widths `w-[min(…)]` in six components (`skills/library.tsx`, `policy/rule-editor.tsx`, `agents/grant-editor.tsx`, `admin/runners-view.tsx`, `credentials/give-access.tsx`); `max-w-[1160px]`/`max-w-[880px]` repeated across about forty pages; `tracking-[0.06em]`, `grid-cols-[16rem_1fr]`, `max-w-[10rem|24rem|28rem]`; chat `max-w-[80%] rounded-tl-[4px]`, composer `rounded-[12px]`; native checkboxes where `CheckboxField` exists (`skills/skills-view.tsx` ~229, ~301); a hand-rolled `role="alertdialog"` with no focus move (`agents/connect-tab.tsx` ~80–92).
