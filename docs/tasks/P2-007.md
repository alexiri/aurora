## Scope notes
- `AURORA_SIGNING_KEY` and `AURORA_INTERNAL_SECRET` accept keyring lists (`key_id:value`, plus `*_ACTIVE_KEY`); a bare value = ring id `v0`; at most 4 entries.
- Producers use only the active key. Receivers accept any key in the ring.
- Action tokens become `v2.<key_id>.…`, and internal calls carry `X-Aurora-Key-Id`. Old tokens and calls keep working during a rotation, so test a full rotation in that order.
- Write a rotation procedure in `docs/operator/`.
