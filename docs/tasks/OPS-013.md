## Goal
Make the chart, the compose stack and the dev loop do what `docs/15-deployment-operations.md` says, for the deployment-file gaps listed in `docs/operator/README.md` §Known gaps (items 3, 4, 5, 6, 9, 10, 13). Then update that list and the operator pages accordingly.

## Linked requirements
- `docs/15-deployment-operations.md` §Production: Helm, §Development: podman compose (incl. `just dev`), §Backups and state, §Configuration reference (`runner.k8s.node_selector`, `runner.k8s.tolerations`, plugin directory).
- `docs/operator/README.md` §Known gaps:
