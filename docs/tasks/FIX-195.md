# FIX-195: The Mattermost outbound pipeline leaves a nested `<a href>` inside a table cell (a live bare URL)

## Goal
This is security-relevant: link previews and data exfiltration (D-270; the outbound pipeline from FIX-142 and
FIX-182). The CI Watcher found it on 2026-11-20 in CI run 44731990142 (master 571548bd, shard rust-test 4):
`connectors/mattermost/tests/hostile_pipeline.rs:417` failed with "a bare URL is left (the server would fetch
it)". This is a new case after FIX-182.

Minimal input:

```
<a href="https://a.example"> |a|b|
|-|-|
|1|![x](u)| <a href="https://a.example">t</a> see https://e.example/?d=SECRET now </a>
```

Output:

```
|a|b|
|-|-|
|1|🖼 x| <a href="https://a.example">t</a> see [https://e.example/?d=SECRET](https://e.example/?d=SECRET) now
```

The outer anchor is removed, but the inner `<a href="https://a.example">t</a>` survives verbatim in a table
cell. Mattermost doesn't render HTML, so the URL in the attribute reaches the server as bare text and gets
unfurled.

The proptest seed is `cc 0bee1d64f95d04e972d251cd0e3eee62f9766c25e0bdb75685b0a6ee85a76f55`. Add it to
`connectors/mattermost/tests/hostile_pipeline.proptest-regressions` **in the same commit as the fix**: until the
fix lands, it fails CI at random.

## Change
1. Find out why the inner anchor is not converted. Likely causes:
   - the nested-anchor case: an `<a>` inside an `<a>` label that is converted as a document;
   - a table cell, where the HTML converter is not applied;
   - the outer anchor's label path from FIX-182, which converts the label differently.

   Confirm the actual cause in the Completion report.
2. Fix it where it lives, so that **every** `<a href>` in any position (nested, in a table cell, in a list, in a
   quote, in a heading) is converted or neutralised, the same as a top-level one. D-270's invariant must hold
   however the anchor is nested: "no bare `http(s)://` survives outside a closed code span".
3. Check the other HTML elements that carry a URL in an attribute (`<img src>`, `<iframe src>`, `<link href>`,
   `<area href>`, `<form action>`, and `<a href>` with `javascript:` and `data:` URLs) in the same nested and
   table positions.
4. Never weaken a check to make the property pass. The last line of defence, `is_safe`/`has_bare_url`, stays
   unchanged.

## Tests
- The seed as a committed regression case, seen failing first.
- Unit or pipeline tests:
  - a nested anchor inside an anchor, and an anchor in a table cell, in a list item, in a quote and in a
    heading: no bare URL in any output;
  - the same positions for the other URL-carrying elements;
  - an ordinary top-level link is unchanged.
- Gate (targeted, owner 2026-11-19):
  - the `hostile_pipeline` tests, and the proptest once with `PROPTEST_CASES=20000` (release);
  - the `aurora-channels` and sanitize tests of the touched code;
  - clippy on the touched crates, and guards.

  Run them through heavy.sh.
- The Completion report states why the fix cannot leave a fetchable URL. The Orchestrator does a security
  review before merge.
